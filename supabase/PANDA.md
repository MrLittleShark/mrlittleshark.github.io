# 熊猫成长系统维护

熊猫使用现有 GitHub / Supabase 账号。入口在个人中心的“我的熊猫”；登录用户也可点击浮动熊猫下方的名字进入。

## 经验规则

| 活动 | 经验 | 规则 |
| --- | ---: | --- |
| 签到 | 10 | 北京时间每日一次 |
| 完成课程 | 25 | 每个已发布课程单元计一次；已有完成记录自动补入 |
| 新讨论 | 15 | 每日最多 3 次 |
| 回复他人讨论 | 5 | 每日最多 6 次 |
| 文章评论 | 3 | 每日最多 5 次 |
| 文章或日志发表 | 30 | 审核发表后计入，每日最多 1 次 |

回复、评论至少包含 10 个非空白字符。自我回复、自我评论和同一天的重复内容不计经验。社区内容删除或隐藏时收回相关经验，奖励事件仍保留，防止重新创建或恢复内容时反复计分。课程撤销完成、重新标记或删除个人进度后重建，均不会重复加分。

等级 `L` 的累计经验门槛是 `25 * L * (L - 1)`。Lv.2 / 3 / 4 / 5 / 10 分别需要 50 / 150 / 300 / 500 / 2250 经验。数据库返回当前等级、下一等级门槛与解锁结果，前端仅显示。

## 文件与数据

- `themes/foam-lab/source/assets/panda-art.js`：SVG 角色、服饰与形态。
- `panda-pet.js`：交互、轮换技巧、账号收藏；搜索调用已有 `foamOpenSearch`。
- `panda-pet.css`：动作、浮层与收藏面板。
- `panda-theme.css`：全站奶白 / 竹青主题与暗色主题。
- `panda-notes.js`：把部分现有操作提示显示为“熊猫说”，不修改正文内容。
- `foamlab_pets`：经验、名字、已装备收藏、显示与动画设置。
- `foamlab_pet_events`：奖励来源、幂等键与每日额度记录。
- `foamlab_private.pet_items`：收藏目录及解锁等级。

姓名、装备、经验与偏好跨设备保存；拖动位置保存在当前设备。浮动层可收起，右下角的小熊猫按钮可以恢复。关闭动画或系统启用“减少动态效果”时停止动作。用户退出后立即移除浮动层，未完成请求的结果会被丢弃。

## 数据库接口

`foamlab_pet(operation, payload)` 是唯一客户端写入口，仅向已登录、具有 GitHub 身份且未被停用的用户开放。操作为 `state`、`checkin`、`equip`、`settings`。客户端没有直接写经验、奖励流水或收藏目录的权限。

奖励由课程、讨论、评论、内容发布的数据库触发器产生。每个用户的奖励事务先锁定宠物记录；唯一事件键避免重复领取。修改规则时请更新数据库函数与个人中心规则说明，并通过测试后部署。

增加收藏需要同时修改数据库目录和 SVG / CSS，保持 `id` 一致。请新建迁移，不要修改已应用的历史迁移。收藏目录位于私有 schema，前端通过账号 RPC 读取。

## 验证

- `supabase/tests/panda-companion.sql`：权限、签到幂等、课程重复标记、每日上限、收藏校验、管理隐藏与经验扣回。测试数据在事务结束时回滚。
- `tools/check-panda.cjs`：本地模拟账号的浏览器检查，涵盖点击 / 双击、拖动、搜索、收藏、移动端、暗色、减少动画与退出竞态。
- `tools/check-cms-ui.cjs`：原有学习、社区与管理流程回归。

发布仍使用项目原有 Hexo → GitHub Actions → GitHub Pages 流程。
