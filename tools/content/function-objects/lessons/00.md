计算过程中，我们常常关心几个具体问题：某一点的速度怎样变化？入口流量是多少？物体受到多大的力？`functionObject` 就是运行这些计算的功能对象。把它写进 `controlDict`，求解器就会按设定的频率执行；已有结果也可以用 `postProcess` 处理。

这一课用方腔算例计算速度大小，并读取两个位置的速度。方腔边长 0.1 m，顶盖以 1 m/s 沿 x 方向移动，`icoFoam` 从 0 算到 0.5 s，时间步为 0.005 s。

## 1. 下载并运行方腔算例

下载本页的 `01-cavity.zip`，解压后进入 `01-cavity`。在已加载 OpenFOAM v2512 的终端运行：

```bash
bash Allrun
```

脚本依次生成网格、检查网格、运行 `icoFoam`，然后对保存的结果做离线后处理。网格是 20 × 20 × 1，z 方向厚度 0.01 m。每 10 步保存一次完整场，因此 `0.05/`、`0.1/`，直到 `0.5/` 都会出现。

算例把后处理设置集中放在 `system/functions`。`system/controlDict` 末尾通过下面的写法加载它：

```foam
functions
{
    #include "functions"
}
```

这里的 `#include` 会把文件内容放进外层 `functions` 字典。下载包的 `system/functions` 因此直接从各个对象的名称开始。

## 2. 第一个对象：从 U 得到速度大小

打开 `system/functions`，找到 `speed`：

{{fo:01-cavity:speed}}

| 条目 | 本例设置的含义 |
|---|---|
| `speed` | 对象名称，由我们命名，用于区分不同任务 |
| `type mag` | 对输入场取模，向量速度变成标量速度大小 |
| `libs (fieldFunctionObjects)` | 加载场运算工具库 |
| `field U` | 输入场为速度 `U` |
| `result speed` | 输出场命名为 `speed` |
| `writeControl timeStep` | 按计算步数控制写出 |
| `writeInterval 10` | 每 10 步写出一次，本例对应 0.05 s |
| `errors strict` | 配置或运行错误会直接显示并结束运行，便于定位问题 |

速度大小的计算是：

$$|\mathbf U|=\sqrt{U_x^2+U_y^2+U_z^2}.$$

本例为二维流动，$U_z=0$。打开 `0.5/speed`，可以看到每个单元的标量值。在 ParaView 中打开 `case.foam`，选择时间 0.5，再选择 `speed`，就得到速度云图。

![方腔速度与中心线剖面](/assets/science/functionobjects-sampling.png)

左图的两个圆点是探针位置。顶盖带动腔内形成回流，因此中心竖线上部的水平速度为正，中下部出现负值。

## 3. 同一个对象，可以在线或离线运行

在线运行时，求解器中的场已经在内存里，功能对象可以直接使用。离线运行时，`postProcess` 从选定的时间目录读场，然后执行后处理。下面五种调用均可在已经运行完的方腔目录中使用。

**示例 1：处理最后一个已保存时刻。**

```bash
postProcess -func 'mag(U)' -latestTime
```

`mag(U)` 是预配置模板调用，输出名称通常为 `mag(U)`。它与本课手写配置的 `result speed` 命名不同，两者计算的是同一物理量。

**示例 2：指定 0.5 s，计算压力梯度。**

```bash
postProcess -func 'grad(p)' -time 0.5
```

本算例的 `p` 是运动压力，单位为 m²/s²，因此 `grad(p)` 的单位为 m/s²。

**示例 3：计算涡量。**

```bash
postProcess -func vorticity -latestTime
```

**示例 4：一次运行两个涡结构工具。**

```bash
postProcess -funcs '(Q Lambda2)' -latestTime
```

外层引号把整组函数作为一个参数传入，括号表示 OpenFOAM 列表。

**示例 5：使用自己的后处理字典。**

```bash
postProcess -dict system/postProcess -latestTime
```

本例的独立字典先读 `U`、`p`，再生成 `postSpeed` 和涡量：

{{file:01-cavity/system/postProcess}}

`-dict` 适合把不同分析任务保存成文件，例如一份用于采样，一份用于积分。下次对新结果运行同一个字典，就能保持处理方式一致。

## 4. 到哪里找结果

| 结果类型 | 本例文件 | 用途 |
|---|---|---|
| 每个单元上的场 | `0.5/speed`、`0.5/vorticity` | 在 ParaView 中着色、切片、画等值面 |
| 探针时间序列 | `postProcessing/pointHistory/0/U` | 画速度随时间变化的曲线 |
| 沿线采样 | `postProcessing/centreLines/0.5/vertical_p_U.xy` | 比较剖面、实验数据和不同网格 |
| 统计量 | `postProcessing/volumeMean/0/volFieldValue.dat` | 读取体积平均值等少量数据 |
| 截面文件 | `postProcessing/midPlane/0.5/midZ.vtp` | 单独保存选定截面及其场 |

探针目录中的 `0` 表示这次记录开始时的时间。文件里会继续追加 0.005、0.01 等采样时刻；它与按时刻分别保存的完整场目录采用不同组织方式。

## 5. 带物理模型的后处理

`yPlus`、壁面剪切应力等工具会读取湍流模型。它们适合随求解器运行，也可以由原求解器加载模型后再处理。配套的后台阶算例使用：

```bash
simpleFoam -postProcess -func yPlus -latestTime
```

后续课程会分别介绍各类工具。下一课先弄清它们共用的时间控制和输出参数。
