计算监测应同时包含代数求解、守恒和物理量。`solverInfo` 记录残差和迭代次数，`continuityError` 汇总连续性误差，`CourantNo` 给出局部时间步指标。本课把它们配置在同一个方腔算例里。

## 1. 保存残差和线性迭代次数

{{fo:01-cavity:residuals}}

`fields (p U)` 选择压力与速度方程。`solverInfo.dat` 中包含求解器名称、初始和最终残差、迭代次数等列。

| 参数 | 默认 / 含义 |
|---|---|
| `fields` | 必填，要监测的方程字段列表 |
| `writeResidualFields` | 默认 `false`，开启后可输出局部残差场 |
| `writeControl`、`writeInterval` | 本例每一步记录 |
| 文本参数 | 可设置 `writePrecision`、`writeToFile` 等 |

初始残差反映本次线性求解开始时的方程不平衡；最终残差与迭代次数反映本次线性求解的结束状态。一次 PIMPLE / PISO 时间步中可能多次求同一个方程，具体记录应结合文件头和求解循环理解。

残差下降后，还要看流量、力或温度这些关心的物理量怎样变化。例如后台阶的入口出口流量差会随迭代改变，它提供了独立于线性残差的检查。

## 2. 连续性误差

{{fo:01-cavity:continuity}}

主要字段参数是 `phi`，默认也叫 `phi`。工具由面通量的散度计算局部、全局和累计误差，并写到：

```text
postProcessing/continuity/0/continuityError.dat
```

局部绝对误差能反映各单元不平衡的整体大小；有符号全局误差会发生正负抵消；累计量用于观察误差是否长期偏向一侧。把三者放在一起读，比只看其中一个数更完整。

## 3. 输出每个单元的 Courant 数

{{fo:01-cavity:courant}}

常用的有限体积表达式为：

$$Co_i=\frac{\Delta t}{2V_i}\sum_{f\in i}|\phi_f|.$$

| 参数 | 默认 / 作用 |
|---|---|
| `field` | 默认 `phi`，用作通量 |
| `rho` | 默认 `rho`，质量通量需要密度换算时使用 |
| `result` | 可指定输出名，本例 `Co` |

`Co` 场可以显示大 Courant 数出现在哪里。小单元、高速度和较大时间步都会提高局部值。日志里的最大 Courant 数告诉你极值大小，场文件则告诉你位置。

## 4. 其他诊断工具如何选

| 工具 | 主要条目 | 回答的问题 |
|---|---|---|
| `PecletNo` | `field`（通量）、`rho`、`result` | 对流相对于扩散有多强；需读取相应输运模型 |
| `MachNo` | `field`（通常 `U`）、`result` | 速度相对于当地声速有多大；声速来自热物性 |
| `AMIWeights` | `writeFields` 等 | AMI 接口的插值权重和覆盖情况 |
| `processorField` | 公共区域和输出参数 | 每个单元属于哪个并行分区 |
| `timeInfo` | `perTimeStep`，默认 `false` | CPU 时间和实际耗时，或逐步耗时 |
| `caseInfo` | `dictionaries`、`writeFormat` | 把选定字典和算例信息保存为字典或 JSON |
| `wallShearStress` / `yPlus` | 壁面与模型参数 | 近壁分辨率及摩擦分布 |

## 5. 建立一组计算监测量

先记录残差，再加入连续性误差、Courant 数、关键位置探针和整体物理量，这是五个逐步增加的监测层次。不同问题的最后一项可以分别选择：通道的压降、物体的力、传热问题的热功率、两相流的水量。

短期残差下降而力仍在缓慢变化时，可以继续计算；瞬态周期流动的瞬时力持续振荡时，则检查周期、均值和振幅是否稳定。监测量的选择应对应最终要回答的物理问题。
