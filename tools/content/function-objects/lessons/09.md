`forces` 计算选中壁面的压力力、黏性力和力矩；`forceCoeffs` 再把它们无量纲化。本课用后台阶通道的上下壁面说明设置方法，运行后能得到随稳态迭代变化的力系数曲线。

## 1. 先确定统计对象与压力单位

解压后台阶包并运行 `bash Allrun`。本例选择 `upperWall`、`lowerWall`，入口速度 10 m/s，密度取 1 kg/m³。`simpleFoam` 的 `p` 是运动压力，所以把 `rho` 指定为常数密度模式。

{{fo:02-pitzDaily:wallForces}}

`CofR (0 0 0)` 是力矩参考点。压力和剪切力即使不变，参考点改变后，力臂发生变化，力矩也会变化。

## 2. forces 的主要参数

| 参数 | 默认 / 可设置值 | 含义 |
|---|---|---|
| `patches` | 必填，名称或匹配表达式列表 | 要统计的物体表面 |
| `p` | 默认 `p` | 压力字段名 |
| `U` | 默认 `U` | 速度字段名，用于黏性应力 |
| `rho` | 默认 `rho`；常数密度用 `rhoInf` | 从密度场读取，或使用固定密度 |
| `rhoInf` | 常数密度模式填写 | kg/m³；对运动压力恢复有量纲压力力 |
| `pRef` | 默认 `0` | 参考压力水平 |
| `CofR` | 参考点坐标 | 力矩中心，单位 m |
| `coordinateSystem` | 可选坐标系子字典 | 定义局部原点和方向；也可按接口支持的轴条目设置 |
| `directForceDensity` | 默认 `false` | 直接对力密度场积分 |
| `fD` | 直接力密度模式的字段名 | 配合 `directForceDensity` |
| `porosity` | 默认 `false` | 纳入多孔介质模型的力贡献 |
| `writeFields` | 默认 `false` | 额外写局部力相关字段，便于查看贡献位置 |

有量纲压力通常以 Pa 保存，可直接用于压力积分；运动压力需要密度换算。可压缩算例一般从 `rho` 场读取密度。先检查 `p` 的量纲，再选择相应的密度来源。

## 3. 设置升阻力系数

{{fo:02-pitzDaily:wallCoefficients}}

参考动压为 $q_\infty=\tfrac12\rho_\infty U_\infty^2$，力和力矩系数通常写为：

$$C_D=\frac{\mathbf F\cdot\mathbf e_D}{q_\infty A_\mathrm{ref}},\qquad C_M=\frac{\mathbf M\cdot\mathbf e_M}{q_\infty A_\mathrm{ref}L_\mathrm{ref}}.$$

| 新增参数 | 本例 | 设置原因 |
|---|---|---|
| `magUInf` | `10` | 参考速度与入口速度相同 |
| `lRef` | `0.0254` | 采用 25.4 mm 的特征长度 |
| `Aref` | `0.0000254` | 25.4 mm × 1 mm 的参考面积，与二维模型厚度一致 |
| `dragDir` | `(1 0 0)` | 阻力沿主流 x 方向 |
| `liftDir` | `(0 1 0)` | 升力沿 y 方向 |
| `coefficients` | 可选列表 | 只输出所需的系数，如 `Cd`、`Cl`、`CmPitch` |

本例的侧向轴由正交坐标系生成，为负 z 方向。输出文件头中会列出 `dragDir`、`liftDir`、`pitchAxis` 等实际轴向。读俯仰力矩系数时，以文件头中记录的方向为准。

二维算例仍然具有实际厚度。参考面积应使用“参考长度 × 建模厚度”，这样网格厚度与归一化面积相互一致。若将 `Aref` 加倍，同一力对应的系数会减半。

## 4. 读取结果与判断迭代趋势

```text
postProcessing/wallForces/0/force.dat
postProcessing/wallForces/0/moment.dat
postProcessing/wallCoefficients/0/coefficient.dat
```

力文件按压力、黏性和总贡献组织；系数文件头给出列名。读取 `Cd`、`Cl` 时按标题定位列，方便以后启用更多系数。

## 5. 压力转换也可以自动完成

{{fo:02-pitzDaily:staticPressure}}

它把运动压力转换成有量纲静压 `pPa`。

| `pressure` 参数 | 可设置的内容 |
|---|---|
| `mode` | `static`、`total`、`isentropic`、`staticCoeff`、`totalCoeff` |
| `field`、`U`、`rho` | 输入压力、速度和密度场，默认 `p`、`U`、`rho` |
| `rhoInf` | 常数密度或系数归一化所需密度 |
| `pRef` | 参考压力，默认 0 |
| `hydrostaticMode` | `none`、`add`、`subtract`，默认 `none` |
| `g`、`hRef` | 加减静水压项时使用；可从已有数据库获取或明确填写 |
| `pInf`、`UInf` | 压力系数的参考压力和速度向量 |
| `result` | 输出场名称 |

五个渐进任务是：单壁面受力、多壁面合力、改变力矩参考点、计算系数、输出有量纲压力。完成这些步骤后，再扩展到翼型、圆柱或旋转设备。
