近壁网格是否合适，可以从 `yPlus` 开始检查；哪里受到较大摩擦，可以看 `wallShearStress`；要进一步分析模型预测的湍流，则用 `turbulenceFields` 输出 `k`、耗散率和应力等量。

## 1. 先运行带湍流模型的算例

后台阶包使用 `simpleFoam` 和湍流模型，`Allrun` 先求解，再用求解器的后处理模式计算最后时刻的 `yPlus`：

```bash
bash Allrun
```

其中离线调用是：

```bash
simpleFoam -postProcess -func yPlus -latestTime
```

这一步会加载该求解器的模型，使壁面工具能够读取所需的湍流和物性信息。

## 2. yPlus 的意义与配置

{{fo:02-pitzDaily:yPlus}}

$$y^+=\frac{u_\tau y}{\nu},\qquad u_\tau=\sqrt{\frac{|\tau_w|}{\rho}}.$$

$y$ 是壁面到近壁单元中心的距离，$\nu$ 为运动黏度。`yPlus` 把第一层单元位置表示成壁面单位，便于与所采用的近壁处理方法对照。

| 参数 | 默认 / 可选值 | 用法 |
|---|---|---|
| `type`、`libs` | `yPlus`、`(fieldFunctionObjects)` | 壁面无量纲距离 |
| `useWallFunction` | 默认 `true` | 优先使用可用壁面函数给出的 y+；关闭后采用工具的直接计算路径 |
| `region` | 默认 `region0` | 多区域时选择流体区域 |
| 输出控制 | 通用参数 | 本例随主场写出 |

结果在 `100/yPlus`，文本统计位于 `postProcessing/yPlus`。在 ParaView 中只显示壁面并按 `yPlus` 着色，可以直接找出第一层网格过粗或变化明显的区域。

采用解析黏性底层的方案时，通常将首层目标设在 $y^+\approx1$ 附近；使用壁面函数时，目标区间应结合具体壁面函数和流动条件。先确定近壁模型，再反推第一层高度。

## 3. wallShearStress：方向也很重要

{{fo:02-pitzDaily:wallShearStress}}

| 参数 | 说明 |
|---|---|
| `patches` | 可选壁面列表；省略时处理可用壁面 |
| `writeControl`、`writeInterval` | 输出频率 |
| `region` | 所属网格区域 |

它输出壁面剪切应力向量，既有大小也有方向。后台阶后方会出现回流，沿壁面的剪切分量可能变号；把 x 分量沿下壁面绘出，有助于观察分离与再附着区域。

输出量纲取决于动量模型：不可压缩模型常得到运动学应力，单位 m²/s²；乘以密度后是 Pa。读取结果文件的 `dimensions` 可以确定当前模型采用哪一种。

## 4. turbulenceFields：把模型内部量保存出来

{{fo:02-pitzDaily:turbulenceFields}}

本例选择 `k`、`epsilon`、`nut` 和 `R`：

| 字段 | 物理意义 | 常见单位 |
|---|---|---|
| `k` | 湍动能 | m²/s² |
| `epsilon` | 湍动能耗散率 | m²/s³ |
| `omega` | 比耗散率，由适用模型提供 | s⁻¹ |
| `nut` | 湍流运动黏度 | m²/s |
| `nuEff` | 有效运动黏度 | m²/s |
| `R` | 雷诺应力张量 | m²/s² |
| `devReff` | 有效偏应力，适用于不可压缩接口 | m²/s² |
| `mut`、`muEff` | 湍流 / 有效动力黏度，适用于可压缩接口 | Pa·s |
| `alphat`、`alphaEff` | 湍流 / 有效热扩散相关系数，由热物性接口定义 | 按模型量纲读取 |
| `devRhoReff` | 含密度的有效偏应力 | Pa |
| `nuTilda` | 修正湍流黏度的估计量 | m²/s |
| `L`、`I` | 长度尺度、湍流强度 | m、无量纲 |

`fields` 选择所需列表，也可按工具接口用单个 `field`。`prefix` 默认是 `turbulenceProperties`，用来区分输出来源。这些字段通过所选模型的接口获得，因此在更换模型时，同时调整字段列表。模型已有的场会被复用，新计算的量通常带有如 `turbulenceProperties:` 的名称前缀。DES 区域指标由单独的 `DESModelRegions` 工具提供。

## 5. 用一套输出检查近壁计算

先看 `yPlus` 的分布，再看剪切应力的大小和方向；接着查看 `nut`，判断模型黏度在哪些位置较强；然后对照 `k` 与 `R`，最后沿壁面或截面采样。五个步骤把网格、摩擦与湍流模型联系起来。

配套包保存了参考文本结果。模型生成的字段可在 ParaView 的字段列表中选择；批量比较不同网格时，沿用相同的采样位置和绘图范围。
