一个后处理对象有两种工作：**计算或更新结果**，以及**把结果写到文件**。对应的设置分别是 `executeControl` 和 `writeControl`。例如时间平均需要每一步都积累数据，但平均场可以每隔一段时间才保存。

## 2. 对象身份与工作区域

| 参数 | 可设置的值 / 默认 | 作用及设置方法 |
|---|---|---|
| `type` | 必填，工具类型名 | 例如 `probes`、`fieldAverage`、`forces`，大小写与类型名一致 |
| `libs` | 库名列表 | 常用 `(fieldFunctionObjects)`、`(sampling)`、`(forces)`、`(utilityFunctionObjects)` |
| `enabled` | `true` / `false`，默认 `true` | 控制是否启用，保留配置时可暂时关闭 |
| `log` | 默认 `true` | 控制该工具的常规日志输出；具体日志由工具实现 |
| `region` | 网格区域名，默认 `region0` | 多区域传热时指定流体或固体区域；适用于基于区域网格的对象 |
| `useNamePrefix` | 布尔值，受对象和全局设置影响 | 让派生场带上对象名前缀，方便区分多个同类计算 |
| `errors` | `default`、`warn`、`ignore`、`strict` | 错误处理方式；教程算例使用 `strict`，错误直接反馈到运行结果 |

对象名与 `type` 分开命名很有用。例如 `inletPressure` 和 `outletPressure` 都可以使用 `surfaceFieldValue`，分别处理不同边界。

## 3. 时间范围与控制方式

| 参数 | 默认值 | 说明 |
|---|---|---|
| `timeStart` | `0` | 对象开始生效的模拟时间 |
| `timeEnd` | 无有限上限 | 对象停止生效的模拟时间 |
| `executeControl` | `timeStep` | 何时调用计算 / 更新操作 |
| `executeInterval` | `1` | 计算间隔；单位随控制方式变化 |
| `writeControl` | `timeStep` | 何时调用写出操作 |
| `writeInterval` | `1` | 写出间隔；单位随控制方式变化 |

`executeControl` 与 `writeControl` 都使用下面这些取值：

| 控制方式 | 间隔的含义 | 适用情景 |
|---|---|---|
| `timeStep` | 计算步数，例如 `10` 步 | 固定时间步采样、稳态迭代监测 |
| `writeTime` | 求解器完整场输出的次数 | 截面和派生场与主结果同步 |
| `runTime` | 模拟时间，例如 `0.05` s | 以物理时间安排输出，实际调用落在计算步上 |
| `adjustableRunTime` | 模拟时间，并参与输出时间对齐 | 与可调整时间步配合；同时协调主 `controlDict` 的时间步和输出设置 |
| `clockTime` | 已用墙钟时间，秒 | 长任务按实际等待时间输出 |
| `cpuTime` | 已用 CPU 时间，秒 | 按计算消耗安排输出 |
| `onEnd` | 计算结束时 | 只保存最终统计或结果 |
| `none` | 关闭此项调度 | 分别控制计算和写出 |

对于 `simpleFoam`，`timeStep` 通常对应一次稳态迭代。`writeInterval 10` 的意思是每 10 次迭代输出，不表示 10 s 的真实流动时间。

## 4. 五种实际安排

| 任务 | 配套算例里的对象 | 执行和输出方式 | 为什么这样设 |
|---|---|---|---|
| 观察启动过程 | `pointHistory` | 每一步采样写出 | 0.005 s 的分辨率能看清速度最初的变化 |
| 保存速度大小 | `speed` | 每步可计算，每 10 步写出 | 派生场与完整场同为 0.05 s 一份 |
| 保存截面 | `midPlane` | 每次主结果输出时写出 | 将截面与三维场对齐 |
| 时间平均 | `averages` | 从 0.1 s 起每步积累，每次主输出时保存 | 统计窗口和保存间隔各自明确 |
| 稳态力系数 | `wallCoefficients` | 每 10 次迭代保存 | 用较小文本文件观察迭代趋势 |

这些对象都在配套案例的 `system/functions` 中。打开同一个文件比较它们，能直接看出时间控制如何与具体任务组合。

## 5. 文本输出参数

许多监测工具继承 `writeFile`，可以使用下表。`mag` 这类直接写 OpenFOAM 场的工具，保存格式主要受 `controlDict` 的场写出设置控制。

| 参数 | 默认 | 含义 |
|---|---|---|
| `writeToFile` | `true` | 写出统计文本文件 |
| `writePrecision` | 系统默认精度 | 文本数字的有效位数；对比微小差值时可增大 |
| `useUserTime` | `true` | 按用户时间单位输出；发动机等算例可能使用曲轴转角 |
| `updateHeader` | `true` | 在需要时更新文件头，反映当前字段或区域设置 |

本专题的场文件使用 ASCII 格式和 10 位精度，便于直接查看及绘图。`writePrecision` 控制保存的数字位数；线性方程的容差仍由 `fvSolution` 设置。

## 6. 组合顺序与依赖

本算例先定义 `speed`，后定义使用 `speed` 的 `speedHistogram`。这样后一个对象读取的是本步已经计算出的速度大小。类似地，离线处理先用 `readFields` 读入 `U`，再计算 `mag(U)`。

对于有内部累积状态的对象，例如 `fieldAverage`，保持执行时间连续尤其重要。对一个已保存的时刻计算涡量很自然；计算时间平均则需要完整的采样序列，并选择合适的权重。

较复杂的自动化还可以设置 `controlMode` 为 `time`、`trigger`、`timeOrTrigger` 或 `timeAndTrigger`，并用 `triggerStart`、`triggerEnd` 限定触发区间。这类设置配合 `runTimeControl` 使用，在自动控制一课中展开。
