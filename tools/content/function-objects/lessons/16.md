## 2. 场运算工具

这些类型主要使用 `fieldFunctionObjects` 库。单场工具通常选择 `field`，多场组合通常使用 `fields`，输出名通过 `result` 设置；具体条目见对应工具说明。

| 工具 | 用途 | 主要设置 |
|---|---|---|
| `mag`、`magSqr` | 模和模平方 | `field`、`result` |
| `components` | 拆分向量 / 张量分量 | `field` |
| `add`、`subtract`、`multiply` | 多场相加、相减、相乘 | `fields`、`result` |
| `pow` | 幂运算 | `field`、`n`、`scale`、`offset`、`checkDimensions` |
| `log` | 标量对数及缩放 | `field`、`scale`、`offset`、`clip` |
| `norm` | 按选定范数归一化场 | `field`、`norm`；`Lp` 模式配 `p`，`composite` 配 `divisor`，`divisorField` 配同名字段条目 |
| `grad`、`div` | 梯度、散度 | 输入类型和相应离散格式 |
| `ddt`、`ddt2` | 时间变化相关导数量 | `field`，并保留所需时间历史 |
| `vorticity`、`enstrophy`、`LambVector` | 涡量、拟涡能、Lamb 向量 | `field U` |
| `Q`、`Lambda2`、`flowType` | 旋转与应变特征 | `field U` |
| `surfaceInterpolate` | 单元场插值到面 | `fields ((输入 输出) ...)` |
| `fieldCoordinateSystemTransform` | 转换向量 / 张量坐标系 | `fields`、`coordinateSystem` |
| `exprField` | 表达式生成或修改场 | `field`、`expression`、`action`、`dimensions` |
| `reference` | 相对于参考值生成新场 | 输入场、参考模式与参考位置 |
| `randomise` | 给场添加随机扰动 | 输入场、扰动幅值与结果名 |
| `zeroGradient` | 生成采用零梯度边界的派生场 | 输入字段及筛选方式 |
| `limitFields` | 限定指定场的数值范围 | 字段、上下限及限制方式 |
| `derivedFields` | 生成预定义派生量 | 选定派生字段列表 |

`limitFields`、`exprField` 的修改模式等会改变数据库中的场。需要保留原始场时，采用新的输出名称，将原量和派生量分别保存。

## 3. 几何采样与区域统计

| 工具 | 用途 | 参数重点 |
|---|---|---|
| `probes`、`patchProbes` | 域内与边界点采样 | 坐标、字段、patch、插值 |
| `sets`、`surfaces` | 点集与表面采样 | 几何子字典、字段与格式 |
| `nearWallFields` | 距壁面指定距离处采样 | 壁面、采样距离、输入输出字段对 |
| `streamLine`、`wallBoundedStreamLine` | 流线与沿壁面约束的追踪 | 种子点、追踪方向、寿命、输出字段 |
| `surfaceDistance` | 计算到几何表面的距离 | 表面文件、几何位置与输出 |
| `fieldExtents` | 场值超过阈值的空间范围 | `fields`、`threshold`、`referencePosition` |
| `volFieldValue`、`surfaceFieldValue` | 体 / 面归约 | 选区、操作、权重 |
| `multiFieldValue` | 多个归约值之间的运算 | 子对象、操作与结果筛选 |
| `fieldMinMax`、`fieldStatistics` | 极值和空间统计 | 分量模式、区域、统计量 |
| `histogram` | 分箱分布 | 字段、上下限、箱数或区间 |
| `columnAverage` | 沿网格柱方向平均 | 选择字段和用于定义柱的边界 |
| `binField` | 沿指定坐标分箱统计 | 分箱模型、方向、范围、箱数与字段 |
| `fluxSummary` | 对选定面区汇总通量 | 通量名称、选区模式和参考方向 |
| `momentum`、`momentumError` | 动量统计及方程误差 | 区域、速度、密度及模型来源 |

采样工具一般使用 `sampling` 库；`streamLine` 等场功能对象使用 `fieldFunctionObjects`。配置时以所选工具的 `libs` 为准。

## 4. 湍流、声学与模态

| 工具 | 能得到什么 | 配置前准备 |
|---|---|---|
| `turbulenceFields` | 模型中的 k、耗散率、应力与黏度 | 已创建的湍流模型 |
| `yPlus`、`wallShearStress` | 近壁位置与剪切 | 壁面边界和动量模型 |
| `DESModelRegions` | DES 的 RANS / LES 区域指标 | 对应混合模型 |
| `resolutionIndex` | 网格 / 湍流解析程度指标 | 选定指标模型及所需场 |
| `energySpectrum` | 湍动能谱 | 符合工具要求的速度数据和网格 |
| `DMD` | 动态模态、频率和模态贡献 | 连续快照、采样步长、截断阶数和字段 |
| `Curle` | 基于表面压力等数据的声学估计 | 壁面、声速、观测点与采样时序 |
| `proudmanAcousticPower` | 各向同性湍流噪声功率估计 | 湍动能、耗散率及声速相关数据 |
| `blendingFactor`、`stabilityBlendingFactor` | 混合离散格式指标 | 对流格式和稳定性指标设置 |

声学与模态依赖足够密集、持续足够久的数据。先根据关注频率选择采样间隔和总时长，再开始保存快照，可减少事后发现时间分辨率不足的情况。

## 5. 力、热、化学与其他物理量

| 工具 | 主要用途 | 配置重点 |
|---|---|---|
| `forces`、`forceCoeffs` | 力、力矩及系数 | patch、密度、参考中心、速度、面积和长度 |
| `phaseForces` | 相相关作用力 | 多相系统、相名和模型数据 |
| `propellerInfo`、`bladeForces` | 推进器和叶片载荷 | 旋转轴、几何、参考量与分区 |
| `pressure` | 静压、总压和系数转换 | 压力形式、密度、参考量 |
| `hydrostaticPressure` | 静水压力初始化 / 计算 | 重力、热物性与边界 |
| `wallHeatFlux`、`heatTransferCoeff` | 壁面热流与换热系数 | 热物性、壁面、参考温差 |
| `viewFactorHeatFlux` | 视角系数辐射模型热流汇总 | 辐射模型和参与壁面 |
| `radiometerProbes`、`thermoCoupleProbes` | 辐射计与热电偶模型采样 | 位置、传感器参数及辐射 / 温度场 |
| `comfort` | 热舒适度指标 | 温湿度、速度、人体和衣着参数 |
| `XiReactionRate` | 反应率相关输出 | 对应燃烧模型和反应场 |
| `reactingEulerHtcModel`、`multiphaseInterHtcModel` | 特定多相求解框架的换热 | 相名、区域和匹配的物性模型 |
| `electricPotential` | 电势方程与相关量 | 导电率、边界和方程设置 |
| `scalarTransport`、`energyTransport`、`age` | 额外输运方程或流龄 | 对流通量、扩散、源项和边界条件 |

最后一组会求解额外方程，适合已有速度场上的扩展分析；其配置还包括初始场、边界和 `fvSchemes` / `fvSolution` 中的相关条目。

## 6. 颗粒与两相界面

| 工具 | 主要用途 |
|---|---|
| `interfaceHeight`、`regionSizeDistribution` | 等效液位、连通区域和等效直径分布 |
| `extractEulerianParticles` | 从欧拉相分数输运中提取颗粒事件数据 |
| `cloudInfo` | 颗粒云的数量、质量等概要 |
| `particleDistribution`、`sizeDistribution` | 颗粒属性或尺度分布 |
| `vtkCloud`、`ensightCloud` | 颗粒数据格式导出 |
| `icoUncoupledKinematicCloud` | 在给定流场中追踪单向耦合运动颗粒 |
| `dsmcFields` | DSMC 宏观统计量 |

颗粒类工具需要在算例中选择真实存在的 cloud 名称，并读取相应颗粒属性。粒径、单个计算颗粒代表的实际粒子数与质量统计采用不同权重，整理分布时要明确纵轴表示数量、质量还是体积占比。

## 8. 模板名称与 type 怎样对应

`postProcess -list` 列出的是可以直接调用的预配置模板。模板可能给通用类型填好常用参数，例如 `patchAverage` 使用面统计工具，`forceCoeffsIncompressible` 使用 `forceCoeffs` 并配置不可压缩分支所需条目。

本专题方腔中使用过的模板调用包括 `mag(U)`、`grad(p)`、`vorticity`、`Q`、`Lambda2`。从模板入手容易快速看到结果；需要指定区域、权重和输出名称时，展开成字典更便于维护。

类型的完整参数可沿“类型名 → 官方 API 的 Usage → 所继承接口”查阅。字段运算常继承 `fieldExpression`，文本监测常继承 `writeFile`，时间调度使用公共控制。先查本类型专用条目，再补公共条目，就能把配置组织完整。
