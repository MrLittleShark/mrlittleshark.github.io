平均流场可以过滤快速变化，帮助观察长期结构。`fieldAverage` 对整个场随时间累积，保存平均场与脉动二阶矩；`valueAverage` 则对另一个对象已经输出的少量数值继续求平均。

## 1. 设置统计起点与采样频率

本课仍使用方腔包。它从 0 s 运行到 0.5 s，从 0.1 s 开始统计，每一步更新平均值：

{{fo:01-cavity:averages}}

`timeStart 0.1` 表示 0.1 s 前的数据不参与这个对象的累积。本例流动很快趋于稳定，适合观察平均文件的生成过程。湍流算例中，应根据流动达到统计稳定的时间选择起点，再留出足够长的采样区间。

## 2. 每个字段都要说明平均方式

| 字段内参数 | 可设置值 / 默认 | 含义 |
|---|---|---|
| `mean` | 必填，`yes` / `no` | 输出该场的平均值 |
| `prime2Mean` | 必填，`yes` / `no` | 输出脉动二阶矩，使用时同时启用平均 |
| `base` | 必填，`time` / `iteration` | 用时间步长加权，或每次执行等权 |
| `window` | 默认无固定窗口 | 使用有限统计窗口时给出长度 |
| `windowType` | `none`、`approximate`、`exact` | 全历史、近似窗口或精确滑动窗口 |
| `windowName` | 可选名称 | 区分多个窗口结果 |
| `allowRestart` | 默认 `true` | 是否允许用保存的统计状态继续累积 |

选择 `base time` 时：

$$\overline{\mathbf U}=\frac{\sum_n\mathbf U^n\Delta t_n}{\sum_n\Delta t_n}.$$

时间步长改变后，每个样本仍按它代表的时间长度加权。选择 `base iteration` 时，权重相等，适合用迭代样本定义统计的任务。

本例对 `U` 同时开启 `mean` 和 `prime2Mean`，得到 `UMean` 和 `UPrime2Mean`；对 `p` 只生成 `pMean`。

## 3. UPrime2Mean 的六个分量是什么

定义脉动 $\mathbf u'=\mathbf U-\overline{\mathbf U}$，二阶矩为：

$$\overline{\mathbf u'\mathbf u'}=\overline{\mathbf U\mathbf U}-\overline{\mathbf U}\,\overline{\mathbf U}.$$

它是对称张量。三个对角分量分别是 x、y、z 速度脉动的方差，非对角分量表示相关性。可由对角项求脉动均方根，例如 $u_{x,\mathrm{rms}}=\sqrt{\overline{u_x'^2}}$。

在 LES 中，这些量反映被解析的非定常速度脉动。RANS 模型给出的 `k`、`R` 属于模型统计量，含义和来源应在后处理中分别标明。

## 4. 从文件继续累计

| 外层参数 | 默认 | 含义与典型用途 |
|---|---|---|
| `restartOnRestart` | `false` | 重启求解器时是否重新开始统计 |
| `restartOnOutput` | `false` | 每次写出后是否清空累积，适合分段平均 |
| `periodicRestart` | `false` | 按固定周期重新开始统计 |
| `restartPeriod` | 周期重置启用时填写 | 每个统计段的持续长度 |
| `restartTime` | 默认无有限触发时间 | 到指定时刻重新开始 |
| `subRegion` | 可选 | 选择对象数据库中的子区域，例如某个采样区域 |

输出时除了平均场，还会保存统计状态，例如 `0.5/uniform/averagesProperties`。继续计算时保留这些状态，就能延续已累计的样本数和统计时间。

滑动平均有另一种目的：只看最近一段时间。精确窗口会保留更多历史信息，窗口越长、字段越多，存储和内存开销也越大。只想了解整体平均时，先使用本例的全历史累计方式。

## 5. 与探针和空间统计对照

![方腔速度时间序列](/assets/science/functionobjects-statistics.png)

图左显示两个固定位置的速度变化。`fieldAverage` 对每个网格位置做类似的时间累计，因此保存的是一个平均场；`volFieldValue` 则把一个时刻的整片空间归约成一个数。这是时间平均和空间平均的直接区别。

配套文件中同时存在 `averages`、`volumeMean` 和 `pointHistory`。可以先看瞬时 `U`，再看 `UMean`，然后观察 `UPrime2Mean`，最后与探针时间曲线和全域空间平均对照。

## 6. 对力系数等少量数据再平均

`valueAverage` 通过 `functionObject` 指定数据来源，通过 `fields` 指定该对象公布的结果名称。它适合平均 `forceCoeffs` 产生的 `Cd` 等标量结果。

| 参数 | 作用 |
|---|---|
| `functionObject` | 已有功能对象的名字，例如负责计算系数的对象 |
| `fields` | 来源对象公布的结果名列表 |
| `window` | 可选统计窗口 |
| `resetOnRestart` | 是否在重启时重置平均 |
| `tolerance` | 用于平均值变化判断的容差设置 |

先让来源对象稳定输出，再加入数值平均。按这样的顺序配置，能分别检查原始曲线和平均结果。
