点和线适合画曲线，截面适合观察二维分布。`surfaces` 把选定表面上的场导出成独立文件；`streamLine` 则根据一个时刻的速度场追踪流线。

## 1. 输出方腔的中间截面

下载并运行方腔算例。在 `system/functions` 中找到 `midPlane`：

{{fo:01-cavity:midPlane}}

平面经过 `(0 0 0.005)`，法向量是 `(0 0 1)`，因此它就是 z = 0.005 m 的截面。`fields (U p speed)` 同时带出速度、压力和已经由前一个对象生成的速度大小。

`interpolate true` 把单元数据插值到采样表面的点上，适合连续着色。若关注逐单元数值，可选基于单元值的表面表示，再与网格对应。

## 2. surfaces 参数

| 参数 | 默认 / 可设置值 | 含义 |
|---|---|---|
| `type`、`libs` | `surfaces`、`(sampling)` | 创建采样表面集合 |
| `fields` | 必填 | 输出到表面的字段名列表 |
| `surfaceFormat` | 必填，常用 `vtk`、`ensight`、`raw` | ParaView 使用 `vtk` 很方便 |
| `surfaces` | 必填，命名子字典 | 每个子项定义一个表面 |
| `interpolationScheme` | 默认 `cellPoint` | 给插值表面提供场值 |
| `sampleScheme` | 默认 `cell` | 非点插值采样使用的方案 |
| `store` | 默认 `false` | 保存表面对象，供其他功能对象读取 |
| `sampleOnExecute` | 默认 `false` | 执行阶段采样开关 |
| `formatOptions` | 可选 | 写出格式专用设置 |

表面子字典也可单独指定 `surfaceFormat`、`formatOptions` 和 `store`。例如只想保存某一个关键截面时，可以为它单独设置输出方式。

## 3. 打开结果

方腔在 0.5 s 的文件是：

```text
postProcessing/midPlane/0.5/midZ.vtp
```

在 ParaView 中打开它并应用，先用 `speed` 着色，再切到 `p`。截面文件已经包含几何和选择的字段，后续分享这一截面时，无须携带整个三维时间目录。

同一个 `surfaces` 对象可以同时包含多个平面。对长通道，可沿轴向布置入口、中部、出口三张截面；对旋转设备，可布置不同半径的比较面。给表面命名时写清位置，能直接从文件名辨认数据。

## 4. 从平面扩展到等值面

两相溃坝算例使用 `alpha.water = 0.5` 表示水气界面的位置：

{{fo:04-damBreak:freeSurface}}

| 参数 | 含义 |
|---|---|
| `type isoSurfaceCell` | 在单元场上提取等值面 |
| `isoField alpha.water` | 用水相体积分数定义表面 |
| `isoValue 0.5` | 选择体积分数为 0.5 的位置 |
| `interpolate true` | 将 `U`、`p_rgh` 等输出字段插值到界面 |

运行 `04-damBreak` 的 `bash Allrun` 后，打开 `postProcessing/freeSurface/0.2/waterAir.vtp`，可以给界面按速度着色。这样几何由相分数决定，颜色由流动速度决定，两种信息表达在同一张图上。

常见的其他表面类型包括 `patch`（已有边界面）、`faceZone`（已有面区）和 `cuttingPlane`（切平面）。先按几何任务选择类型，再填写这一类型的子参数。

## 5. 追踪方腔中的流线

{{fo:01-cavity:streamlines}}

种子点都在 x = 0.05 m 上，y 从 0.01 到 0.09 m，共 5 点。`direction bidirectional` 从每个点同时沿速度方向和反方向追踪，使回流结构更容易显示。

| 参数 | 默认 / 取值 | 作用 |
|---|---|---|
| `U` | 默认 `U` | 用哪个速度场追踪 |
| `fields` | 必填 | 沿流线保存的字段 |
| `setFormat` | 必填 | 本例为 `vtk` |
| `direction` | `forward`、`backward`、`bidirectional` | 追踪方向 |
| `lifeTime` | 必填，整数 | 追踪寿命的步数上限，注意大写 `T` |
| `nSubCycle` | 默认 `1` | 单元内细分追踪，提高曲线分辨率 |
| `trackLength` | 可选 | 用固定跟踪长度控制步进 |
| `interpolationScheme` | 默认 `cellPoint` | 追踪位置上的速度插值 |
| `seedSampleSet` | 必填子字典 | 种子点集，内部写法与线采样点集相似 |
| `bounds` | 可选包围盒 | 限定追踪范围 |
| `cloud` | 默认取对象名 | 输出流线集合名称 |

输出文件在 `postProcessing/sets/streamlines/0.5/track0.vtp`。先打开该文件，再用 `U` 的模着色；曲线上的箭头可在 ParaView 中通过 Glyph 添加。

流线满足某个时刻的速度方向关系 $d\mathbf x/ds\parallel\mathbf U(\mathbf x,t_0)$。粒子轨迹则随时间积分 $d\mathbf x/dt=\mathbf U(\mathbf x,t)$。本课的 `streamLine` 用于前一种，尤其适合查看稳态流场或某一瞬时流动结构。
