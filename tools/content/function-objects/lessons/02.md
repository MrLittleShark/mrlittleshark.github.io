`probes` 记录指定坐标处的场值，适合速度、压力、温度的时间序列。先确定测点的物理位置，再选择插值方式和记录频率，就能得到可以直接画曲线的数据。

## 1. 在方腔里放两个测点

运行本课方腔包的 `bash Allrun`。方腔范围为 $0\le x,y\le0.1$ m，z 方向厚度 0.01 m。我们把两个测点放在中间截面，分别位于腔体中心和中心上方。

{{fo:01-cavity:pointHistory}}

第一点为 `(0.05 0.05 0.005)`，第二点为 `(0.05 0.075 0.005)`。两点 x 相同，y 不同，因此可以比较回流中不同高度的速度变化。

`fields (U p)` 同时记录向量速度与标量压力。`cellPoint` 利用单元和点上的信息插值到探针位置；探针恰好不在单元中心时，这比直接拿所在单元的值更容易表达位置差别。

## 2. 可设置的参数

| 参数 | 默认 / 取值 | 作用与选法 |
|---|---|---|
| `type`、`libs` | `probes`、`(sampling)` | 加载空间点采样工具 |
| `fields` | 必填，字段名列表，可用匹配表达式 | `(U p)`、`(T)`；字段来自正在运行的算例 |
| `probeLocations` | 必填，坐标列表 | 每个点写成 `(x y z)`，单位与网格一致 |
| `interpolationScheme` | 默认 `cell` | `cell` 使用所在单元值；本例 `cellPoint` 做空间插值 |
| `fixedLocations` | 默认 `true` | 测点保持在指定空间坐标；动网格下设 `false` 可随关联单元运动 |
| `includeOutOfBounds` | 默认 `true` | 保留网格外位置的输出占位，越界值用极大负值表示；本例关闭 |
| `sampleOnExecute` | 默认 `false` | 是否在 execute 阶段额外采样；默认主要由写出调度驱动 |
| `verbose` | 默认 `false` | 增加采样诊断信息 |
| `writeControl`、`writeInterval` | 本例 `timeStep`、`1` | 每一步记录，时间间隔 0.005 s |

测点数可以增加。做实验对比时，直接采用实验探头的坐标；做对称性检查时，则布置成对位置。坐标落在流体网格内，输出才对应所研究的流体。

## 3. 读懂 U 文件的每一列

文件 `postProcessing/pointHistory/0/U` 开头是两个探针坐标，随后每一行先写时间，再依次写各探针的速度向量：

```text
# Probe 0 (0.05 0.05 0.005)
# Probe 1 (0.05 0.075 0.005)
# Time       0                                  1
0.005        (-0.0577744 0.0000063063 0)          (-0.0772819 0.0000085211 0)
```

括号里的顺序是 `Ux Uy Uz`。0.005 s 时两点的 `Ux` 都为负，说明局部速度指向 x 的负方向。顶盖虽然向右移动，腔内回流仍然会向左运动。

![探针时间序列与速度分布](/assets/science/functionobjects-statistics.png)

左图直接使用这个文件绘制。探针 0 与探针 1 经历不同的启动过程，之后逐渐趋于稳定。判断周期或振荡时，可把采样间隔与预期周期相比较；一个周期内保留足够多的数据点，曲线形状才清楚。

## 4. 在壁面上测量：patchProbes

壁面值来自边界条件或壁面模型。`patchProbes` 把给定位置对应到所选边界面，读取壁面上的场值。方腔顶盖的两个测点这样设置：

{{fo:01-cavity:lidProbes}}

其中 `patches (movingWall)` 限定目标边界。y 坐标等于 0.1 m，正好落在顶盖上。顶盖采用固定速度 `(1 0 0)`，所以这里的 `U` 用于确认壁面运动；壁面附近流体的速度变化则由域内 `probes` 查看。

| 条目 | patchProbes 中的含义 |
|---|---|
| `patches` | 目标 patch 名称或匹配表达式，列表写法 |
| `probeLocations` | 用于寻找目标边界采样位置的坐标 |
| `fields` | 要读取的边界场，如 `p`、`U`、`T` |
| `writeControl` | 沿用公共输出调度，本例每 10 步写出 |

## 5. 从两个测点扩展到工程监测

先用一个测点确认坐标和输出，再增加多个测点；接着同时记录 `U`、`p`，最后加入壁面测点或运动网格。这五个层次分别解决位置、空间差异、多物理量、边界值与运动参考的问题。

对于压力信号，还要确认压力单位。方腔的 `p` 是运动压力；把它乘以密度才得到以 Pa 表示的压力差。若需要频谱，先保证连续、均匀的时间采样，再对稳定统计阶段的信号分析。
