两相流的云图展示界面形状，水相体积和液面高度则给出定量信息。本课对溃坝算例同时输出这三类结果，便于把界面运动与守恒联系起来。

## 1. 从初始水柱开始

下载 `04-damBreak.zip`，进入目录运行 `bash Allrun`。脚本生成网格后执行 `setFields`，初始化 `alpha.water`，再由 `interFoam` 计算到 0.2 s。`alpha.water = 1` 表示水，0 表示空气，中间数值表示界面单元中的水相比例。

初始时间步为 0.001 s，启用自适应时间步，`maxCo` 与 `maxAlphaCo` 均为 0.5。每 0.05 s 保存完整场，后处理对象也按各自频率工作。

## 2. 积分相分数，得到水量

{{fo:04-damBreak:waterVolume}}

水相体积为：

$$V_w=\sum_i\alpha_{w,i}V_i.$$

因此输入 `alpha.water`、使用 `volIntegrate`。相分数本身无量纲，积分结果的单位是 m³。二维算例也有厚度，这个体积包含实际建模厚度。

输出位于 `postProcessing/waterVolume/0/volFieldValue.dat`。比较初始与末尾的体积，可以量化计算中的水量变化。

## 3. 沿指定方向测液位

{{fo:04-damBreak:level}}

| 参数 | 默认 / 可设置值 | 含义 |
|---|---|---|
| `alpha` | 默认 `alpha` | 相分数名称，本例明确填 `alpha.water` |
| `locations` | 必填坐标列表 | 定义每根液位测量线的位置 |
| `direction` | 默认从重力方向取得 | 本例 `(0 -1 0)`，与重力方向一致 |
| `liquid` | 默认 `true` | 当前相分数是否表示所测液体；另一种情况使用互补相 |
| `interpolationScheme` | 默认 `cellPoint` | 测量线上的相分数插值 |

`interfaceHeight` 沿测量线积分相分数，得到等效液柱高度。水面单值且界面清楚时，它接近直观水位；出现飞溅、液滴或多层界面时，这个积分含义仍然成立。

两个位置的 x 坐标分别为 0.1 和 0.3 m。前者位于初始水柱附近，后者用于观察水流到达下游后的液位变化。

## 4. hB、hL 和 position 怎样读

```text
postProcessing/level/0/height.dat
postProcessing/level/0/position.dat
```

`height.dat` 对每个位置输出两列：`hB` 是相对于测量线边界的高度，`hL` 是相对于所给测量位置的高度。`position.dat` 输出推算的界面位置坐标。

本例测点位于底部，方向向下，方便以底部作为高度基准。改变测点高度或方向时，这两列的几何基准也会随之改变。

## 5. 同时记录相分数极值和自由表面

{{fo:04-damBreak:waterRange}}

极值记录方便观察界面输运过程中相分数的范围。与总体水量一起检查，就能分别了解局部范围和整体守恒。

{{fo:04-damBreak:freeSurface}}

这里用 `alpha.water = 0.5` 提取界面几何，并将速度、压力带到界面。打开 `postProcessing/freeSurface/0.2/waterAir.vtp` 即可查看。

由浅入深，五项任务依次是：相分数极值、水相体积、一个液位点、多个液位点、带速度着色的自由表面。

## 6. 进一步分析液滴：regionSizeDistribution

喷雾或破碎问题需要把连通液相区域识别出来，再统计尺度分布。`regionSizeDistribution` 按相分数阈值区分连通区域，并将区域体积换算为等效直径。

| 主要参数 | 用途 |
|---|---|
| `field` | 相分数场名称 |
| `threshold` | 划分相区域的阈值 |
| `patches` | 识别与指定边界相连的区域，例如喷嘴液核 |
| `minDiameter`、`maxDiameter` | 等效直径统计区间 |
| `nBins` | 直径分箱数量 |
| `fields` | 额外统计区域内的场，如速度 |
| `setFormat` | 分布数据的输出格式 |
| `coordinateSystem` | 可选局部坐标，用于方向相关统计 |
| `isoPlanes` 及其子参数 | 增加沿参考方向的平面统计 |

等效直径由体积定义为 $d=(6V/\pi)^{1/3}$，表达的是同体积球的直径。使用前先明确液核、液滴及统计直径范围，再结合实际网格分辨率解释小液滴数量。
