空间统计回答的是“这个时刻、这一片区域里的场怎样分布”。本课依次计算极值、体积平均、多个统计量和直方图。时间平均在后面的 `fieldAverage` 一课介绍。

## 1. 找出最大速度及其位置

运行方腔算例。下面的对象记录压力、速度和速度大小的极值：

{{fo:01-cavity:extrema}}

`mode magnitude` 对向量取模后比较；改为 `component` 则分别统计 x、y、z 分量。`location true` 同时记录极值坐标和所属进程，便于回到网格中找到它。

| 参数 | 默认 / 取值 | 说明 |
|---|---|---|
| `fields` | 必填 | 可同时列出标量、向量和张量场 |
| `mode` | 默认 `magnitude`；另有 `component` | 取模比较，或逐分量比较 |
| `location` | 默认 `true` | 输出极值位置 |

## 2. 体积平均与简单平均

{{fo:01-cavity:volumeMean}}

这里的 `regionType all` 表示整个体网格，`volAverage` 按每个单元的体积加权：

$$\overline f_V=\frac{\sum_i f_iV_i}{\sum_iV_i}.$$

简单平均 `average` 为 $\sum_i f_i/N$。均匀网格中两者相同；局部加密网格中，小单元数量很多，简单平均会给加密区更多权重。研究空间整体平均时，通常使用 `volAverage`。

| 参数 | 默认 / 可选值 | 作用 |
|---|---|---|
| `regionType` | 必填：`all`、`cellZone` | 选择全域或单元区 |
| `name` | 选择 `cellZone` 时填写 | 对应网格中的单元区名 |
| `fields` | 必填 | 要统计的场 |
| `operation` | 必填 | 见下表 |
| `postOperation` | `none`、`mag`、`sqrt`，默认 `none` | 对统计结果再取模或平方根 |
| `weightField` / `weightFields` | 加权操作时配置 | 权重字段或多个权重字段的组合 |
| `scaleFactor` | 默认 `1` | 对处理数值施加比例系数 |
| `writeFields` | 默认 `false` | 是否另外写选中区域的场数据 |

| `operation` | 计算内容 | 适用例子 |
|---|---|---|
| `min`、`max` | 最小、最大值 | 最高温度、最低压力 |
| `sum`、`sumMag` | 数值求和、取模后求和 | 离散量汇总 |
| `average` | 按单元数量平均 | 比较等体积单元数据 |
| `volAverage` | 按体积平均 | 全域平均温度 |
| `volIntegrate` | $\sum f_iV_i$ | 水相体积、体积热源总功率 |
| `CoV` | 变异系数 | 量化场分布均匀程度 |
| `weightedSum`、`weightedAverage` | 加权求和、加权平均 | 按用户定义权重统计 |
| `weightedVolAverage`、`weightedVolIntegrate` | 同时使用权重和体积 | 用密度权重计算质量平均 |
| `none` | 跳过归约计算 | 与场输出等任务组合 |

本例 `U` 的体积平均接近零，而 `speed` 的平均为正。向量在不同方向会抵消，速度大小始终非负，所以这两个结果描述的内容不同。

## 3. 一次输出多种统计：fieldStatistics

{{fo:01-cavity:statistics}}

这是 v2512 的场统计工具。它可以对每个字段同时计算多种统计量，并为极值附上详细信息。

| 参数 | 默认 / 可选值 | 作用 |
|---|---|---|
| `fields` | 必填列表 | 本例 `p`、`U` |
| `statistics` | 必填列表：`min`、`max`、`mean`、`variance` | 选择输出的统计量 |
| `mode` | 默认 `magnitude`，另有 `component` | 向量取模或按分量分别处理 |
| `mean` | 默认 `arithmetic`，另有 `volumetric` | 算术平均或体积加权平均 |
| `internal` | 默认 `false` | 设 `true` 只统计内部场，排除边界面值 |
| `extrema` | 默认 `false` | 额外输出极值位置等信息 |

本例把 `internal` 设为 `true`，所以内部最大 `Ux` 约为 0.8527 m/s，而顶盖边界速度为 1 m/s。由统计区域的选择就能解释这个差别。

`variance` 是空间样本方差。它反映同一时刻各位置之间的变化；湍流中某一点随时间的脉动方差要用时间统计计算。

## 4. 直方图：多少区域处在某个速度范围

{{fo:01-cavity:speedHistogram}}

`equalBinWidth` 把 0–1 m/s 分成 10 个等宽区间。输出 `histogram.dat` 中依次有时间、分箱中心、单元数和体积分数。

| 参数 | 等宽模型 `equalBinWidth` | 不等宽模型 `unequalBinWidth` |
|---|---|---|
| `field` | 标量输入场，如 `speed` | 同左 |
| `model` | `equalBinWidth` | `unequalBinWidth` |
| `nBins` | 必填，分箱数量 | 使用 `ranges` 指定区间 |
| `min`、`max` | 指定范围；省略上限时自动获取场范围 | 使用 `ranges ((下限 上限) ...)` |

![速度探针与速度直方图](/assets/science/functionobjects-statistics.png)

图中 0–0.1 m/s 的柱对应体积分数约 0.345。它说明此时约 34.5% 的内部网格体积处于这一速度范围。

## 5. 五种由浅入深的用法

先找最大速度，再输出极值坐标；随后计算平均速度大小，比较 `average` 与 `volAverage`；最后绘制直方图。进一步分析两相流时，把 `volIntegrate` 用在 `alpha.water` 上，就能把空间统计转化为水量守恒检查。
