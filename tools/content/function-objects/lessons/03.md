沿一条直线取出速度或温度，就得到剖面。剖面可以直接比较不同网格，也便于与实验点或解析解放在同一张图里。`sets` 负责这种离散点集采样。

## 1. 提取方腔的两条中心线

运行方腔配套包后，`centreLines` 会在每次场输出时保存两条线：一条固定 x，沿 y 方向；另一条固定 y，沿 x 方向。

{{fo:01-cavity:centreLines}}

先看竖线 `vertical`。`start` 和 `end` 都位于 z = 0.005 m 截面上，x = 0.05 m。y 从 0.0001 到 0.0999 m，略微避开上下壁面，采集的是流体内部的值。`nPoints 51` 将线段均分成 50 个间隔。

横线 `horizontal` 采用同样的方法。它可以用来观察垂直速度 `Uy`，与竖线上观察 `Ux` 互相补充。

## 2. sets 的外层参数

| 参数 | 默认 / 可选值 | 作用 |
|---|---|---|
| `type`、`libs` | `sets`、`(sampling)` | 点集采样 |
| `fields` | 必填 | 本例同时采样 `U` 和 `p` |
| `sets` | 必填，命名子字典或列表 | 每个子项定义一组采样点 |
| `interpolationScheme` | 默认 `cellPoint` | 插值到指定坐标；也可使用 `cell` 等已注册的插值方法 |
| `setFormat` | 必填 | 常用 `raw`、`csv`、`vtk`、`ensight`，按输出用途选 |
| `formatOptions` | 可选子字典 | 为相应写出格式设置选项，例如 ASCII / binary |
| `sampleOnExecute` | 默认 `false` | 选择是否在执行阶段进行采样 |

每个子集合还可以设置自己的 `setFormat`、`formatOptions`，覆盖外层格式；子集合的 `store` 控制是否将采样数据保存在对象数据库，供后续处理使用。所有采样线使用相同格式时，把格式设置放在外层最清楚。

## 3. uniform 线段参数

| 参数 | 本例值 | 说明 |
|---|---|---|
| `type` | `uniform` | 沿线段均匀布点 |
| `axis` | `y` 或 `x` | 输出文件横坐标使用哪个坐标；还可选 `z`、`xyz` 或 `distance` |
| `start`、`end` | 三维坐标 | 线段起点和终点 |
| `nPoints` | `51` | 采样点数量，包含两端 |

`axis` 改变的是输出坐标的表示方法，线的位置仍由 `start`、`end` 决定。倾斜直线使用 `distance`，得到沿线距离；希望保留完整位置时使用 `xyz`。

增加采样点主要让曲线更密。网格只有 20 个单元跨越腔高时，51 个采样点是对现有场插值，空间分辨率仍由原网格决定。研究网格敏感性时，保持同一条采样线，再比较不同网格上的曲线。

## 4. 读取输出并画图

文件位于：

```text
postProcessing/centreLines/0.5/vertical_p_U.xy
postProcessing/centreLines/0.5/horizontal_p_U.xy
```

本例 `vertical_p_U.xy` 的列顺序是 `y p Ux Uy Uz`。标量与向量会按写出器的字段分组组织，因此读取时对照文件名和列数。前几行的 y 值依次为 0.0001、0.002096、0.004092 m。

![中心线采样结果](/assets/science/functionobjects-sampling.png)

右图以 `Ux` 为横轴、y 为纵轴。底部接近静止壁面，速度接近 0；中部为向左的回流；顶部逐渐接近顶盖的正向速度。这张曲线把云图中颜色变化转成了可以定量比较的数据。

## 5. 其他点集怎样选

| 采样几何 | 常用类型 | 主要条目 | 典型用途 |
|---|---|---|---|
| 均匀直线 | `uniform` | `start`、`end`、`nPoints`、`axis` | 通道剖面、方腔中心线 |
| 指定离散点 | `cloud` | `points`、`axis` | 与实验测点坐标逐一对应 |
| 折线 | `polyLine` | `points`、`axis` | 沿弯曲路径串联采样位置 |
| 单元中心穿越线 | `midPoint` | `start`、`end`、`axis` | 查看线段穿过的单元值 |
| 与网格面相交的位置 | `face` | `start`、`end`、`axis` | 对照面位置分析场的变化 |

直线剖面适合从 `uniform` 开始。接下来再练习多条平行线、倾斜线、实验点云和跨区域采样；每增加一组，给它起一个能识别位置的名称，例如 `inletSection` 或 `x050mm`，后续整理结果更方便。
