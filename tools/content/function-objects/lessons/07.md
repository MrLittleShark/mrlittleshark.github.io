速度、压力是求解器直接给出的场。速度大小、梯度、涡量和 Q 值则可以由这些场进一步计算。本课在方腔算例中逐步组合场运算，并说明每种结果的物理含义。

## 1. 从向量得到标量：mag 和 magSqr

{{fo:01-cavity:speed}}

{{fo:01-cavity:speedSquared}}

`mag` 输出 $|\mathbf U|$，单位 m/s；`magSqr` 输出 $|\mathbf U|^2$，单位 m²/s²。后者乘以 0.5 就是单位质量动能。两个对象都用 `field` 选择输入，`result` 指定输出名称。

| 公共参数 | 作用 |
|---|---|
| `field` | 单场运算输入，具体工具有各自默认值，示例明确填写 |
| `fields` | 多场运算的输入列表，如 `add` 使用 `(U U)` |
| `result` | 输出场名称；省略时由工具按类型和输入生成名称 |
| `region` | 所处理的网格区域 |
| `writeControl` / `writeInterval` | 输出频率 |

## 2. 梯度与散度

## 3. 涡量与涡结构指标

{{fo:01-cavity:vorticity}}

涡量定义为 $\boldsymbol\omega=\nabla\times\mathbf U$。方腔主要在 xy 平面内运动，主要涡量分量是 $\omega_z$。正负号对应不同旋转方向，壁面附近的速度剪切也会产生较大的涡量。

{{fo:01-cavity:Qcriterion}}

把速度梯度分解为对称部分 $\mathbf S$ 和反对称部分 $\boldsymbol\Omega$，Q 定义为：

$$Q=\frac12\left(\|\boldsymbol\Omega\|^2-\|\mathbf S\|^2\right).$$

`Q > 0` 表示局部旋转强于应变。Q 的量纲是 s⁻²，显示等值面时应记录所用阈值。

{{fo:01-cavity:lambda2}}

`Lambda2` 取 $\mathbf S^2+\boldsymbol\Omega^2$ 的中间特征值。常用负值等值面观察旋涡核心；改变阈值会改变被显示的范围。

![方腔涡量与 Q](/assets/science/functionobjects-vortex.png)

两张图使用同一时刻、同一网格。涡量图突出旋转方向与剪切；Q 图比较局部旋转和应变。它们回答的问题不同，因此可以互相补充。

| 工具 | 主要输入 | 输出的含义 |
|---|---|---|
| `vorticity` | `field U` | 涡量向量 |
| `Q` | `field U` | 旋转与应变竞争的标量指标 |
| `Lambda2` | `field U` | 中间特征值 |
| `enstrophy` | `field U` | $\tfrac12|\boldsymbol\omega|^2$ |
| `LambVector` | `field U` | $\boldsymbol\omega\times\mathbf U$ |
| `flowType` | `field U` | 用应变和旋转强度区分局部流动类型 |

以上对象都已包含在方腔的 `system/functions` 中，可以在 `0.5/` 找到对应场。

## 5. 用表达式计算单位质量动能

{{fo:01-cavity:energy}}

这里 `field kineticEnergy` 是输出名，`expression` 中的 `U` 是输入场。`dimensions [0 2 -2 0 0 0 0]` 对应 m²/s²。

| `exprField` 参数 | 默认 / 用途 |
|---|---|
| `field` | 要生成或修改的字段名 |
| `expression` | 必填，带引号的表达式 |
| `action` | 默认 `new`，另有 `modify`、`none` |
| `dimensions` | 设置输出量纲 |
| `fieldMask` | `modify` 时选择要更新的位置 |
| `store` | 默认 `true`，把结果留在数据库供后续对象使用 |
| `autowrite` | 默认 `false`，控制对象自动写出属性；自身写出调度仍由功能对象处理 |
| `readFields` | 离线处理时自动读取表达式需要的场 |

组合时把生产数据的对象放在前面。例如先生成 `kineticEnergy`，再用 `volFieldValue` 积分，就能得到动能相关的空间统计量。
