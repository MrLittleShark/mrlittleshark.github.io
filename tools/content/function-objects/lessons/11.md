传热后处理可以分成三种任务：求壁面热流密度、把热流积分成热功率、计算相对于某个温差定义的换热系数。v2512 的 `wallHeatFlux` 还提供 `gauge` 模型，用于预测固定温度热流传感器的读数。

## 1. 运行冷热壁面算例

下载 `03-hotRoom.zip`，解压后运行 `bash Allrun`。计算域为 10 × 5 × 10 m，初始温度为 300 K。底部 `floor` 较热，顶部 `ceiling` 较冷，`buoyantPimpleFoam` 计算到 0.2 s。

这一段短时计算主要用于观察各工具怎样生成结果。壁面温差刚开始影响流体时，内部温度仍接近 300 K。

## 2. 计算所有壁面的热流

{{fo:03-hotRoom:wallHeatFlux}}

`model wall` 使用壁面温度梯度和有效热扩散 / 热物性计算热流。省略 `patches` 时处理所有壁面，并在文本中列出每个壁面的最小值、最大值和面积积分。

| 参数 | 默认 / 可选值 | 作用 |
|---|---|---|
| `model` | 默认 `wall`，另有 `gauge` | 壁面热流，或热流传感器模型 |
| `patches` | `wall` 模型中默认所有壁面 | 选择需要统计的壁面列表 |
| `qr` | 默认 `qr` | 已有辐射热流字段的名字；存在时纳入壁面处理 |
| 输出控制 | 通用参数 | 本例在 0.1、0.2 s 写出 |

结果包括 `0.2/wallHeatFlux` 和 `postProcessing/wallHeatFlux/0/wallHeatFlux.dat`。前者用于在壁面上着色，后者方便直接读取热功率。

0.2 s 时，底壁积分约 −19.8583 W，顶壁约 19.8366 W。这里的符号与壁面外法向及工具的热流约定相联系：热量通过底壁进入流体，通过顶壁流出。比较输入和输出时，把符号与物理方向一起解释。

## 3. 热流密度与热功率

热流密度的单位为 W/m²，总热功率为：

$$\dot Q=\int_A q''\,dA.$$

直接把所有面的热流密度相加，得到的是与面数有关的量；使用面积积分，才得到与实际表面积对应的功率。`wallHeatFlux.dat` 已包含各壁面积分，也可以让 `surfaceFieldValue` 对选定面区做 `areaIntegrate`。

## 4. gauge：模拟固定温度热流传感器

本例把两个传感器放在底壁，固定传感器温度 300 K，只计算对流部分：

| 参数 | 默认 / 取值 | 含义 |
|---|---|---|
| `patch` | 必填，单个 patch | 传感器所在壁面，本例 `floor` |
| `probeLocations` | 必填坐标列表 | 传感器位置；可在同一壁面放多个 |
| `Tgauge` | 必填，K | 传感器温度，本例 300 K |
| `convective` | 默认 `false` | 开启对流热流计算 |
| `radiative` | 默认 `false` | 开启辐射热流计算 |
| `writeFields` | 默认 `false` | 保存传感器结果字段 |
| `T` | 默认 `T` | 流体温度场 |
| `alphat` | 默认 `alphat` | 湍流热扩散字段 |
| `qin` | 默认 `qin` | 入射辐射热流场 |
| `absorptivity` | 默认 `1`，范围 0–1 | 辐射吸收率 |
| `emissivity` | 默认 `1`，范围 0–1 | 表面发射率 |

v2512 的 `gauge` 在构造时就读取 `qin`。本例没有辐射热源，在 `0.orig/qin` 中放置量纲为 W/m² 的零场，并先加载它：

{{fo:03-hotRoom:readRadiation}}

{{file:03-hotRoom/0.orig/qin}}

`readOnStart true` 使字段在其他对象初始化前进入数据库，随后 `heatGauge` 就能读取它。这种“先加载数据、再构造依赖它的对象”的顺序同样适用于其他组合。

`postProcessing/heatGauge/0/convective.dat` 是逗号分隔数据。0.2 s 时，两点的对流热流约为 0.0124020 和 0.0123968 W/m²。传感器温度为 300 K，与实际热壁面温度不同，所以读数与 `model wall` 的热流有不同物理含义。

启用辐射后，模型使用吸收和发射项：$q''_\mathrm{rad}=a q''_\mathrm{in}-\varepsilon\sigma T_g^4$。这时 `qin` 应由相应辐射计算提供。

## 5. heatTransferCoeff：选择温差定义

{{fo:03-hotRoom:heatTransfer}}

本例使用 `localReferenceTemperature`，参考温度来自近壁单元。换热系数与所选温差相联系：

$$h=\frac{q''}{T_w-T_\mathrm{ref}}.$$

| 参数 | 默认 / 可选值 | 作用 |
|---|---|---|
| `field` | 必填 | 温度场，本例 `T` |
| `patches` | 必填列表 | 求换热系数的壁面 |
| `htcModel` | 必填 | 见下表 |
| `qr` | 默认 `qr` | 辐射热流字段名 |
| `L`、`kappa` | 均默认 `1` | 输出按 $L/\kappa$ 缩放，可用于生成 Nusselt 数 |
| `result` | 可选名称 | 本例输出 `htc` |

| 模型 | 温差或物理关系 | 额外设置 |
|---|---|---|
| `localReferenceTemperature` | 使用壁面邻近单元温度 | 由局部场提供参考温度 |
| `fixedReferenceTemperature` | 所有选中壁面共用一个参考温度 | `TRef` |
| `faceZoneReferenceTemperature` | 从指定面区计算参考温度 | `referenceFaceZone`；可用 `referenceRegion` 指定所属区域 |
| `ReynoldsAnalogy` | 用摩擦和传热类比估算 | `UInf`；`U`、`rho`、`Cp` 选择字段，常数参考模式再填写 `rhoInf`、`CpInf` |

保持默认缩放时读取 $h$；若要输出 $Nu=hL/\kappa$，填写实际特征长度和导热系数，并在图表中注明无量纲结果。温差很小的位置会对 $h$ 产生明显影响，因此读换热系数时同时查看壁温和参考温度。
