后处理结果可以保存成 OpenFOAM 场，也可以导出为 ParaView 或 EnSight 文件。本课把“读取字段、生成几何辅助量、选择输出字段、导出文件”连成一套流程。

## 1. 读入已保存的字段

方腔包中的独立后处理字典先使用 `readFields`：

{{file:01-cavity/system/postProcess}}

运行：

```bash
postProcess -dict system/postProcess -latestTime
```

`readFields` 的 `fields` 是要从当前选中时间目录读取的字段列表；`readOnStart` 默认 `true`，在初始化时读取。随后 `savedSpeed` 和 `savedVorticity` 使用这些字段计算结果。

`readFields` 负责把现有数据放进对象数据库。求解器在线运行时，多数主场已经在数据库中，通常可直接使用。

## 2. 输出单元中心和体积

`writeCellCentres` 输出中心坐标 `C` 以及分量 `Cx`、`Cy`、`Cz`；`writeCellVolumes` 输出 `V`。这两个工具适合导出到 Python 后做自定义计算，例如 $\sum_i\alpha_iV_i$。

本专题的结果图就使用了方腔的中心坐标和速度场。将坐标和场一一对应，可以画规则网格图，也可以对非结构网格建立散点或多边形表示。

## 3. 用 vtkWrite 导出选定字段

{{fo:01-cavity:exportVTK}}

| 参数 | 默认 / 可设置值 | 用途 |
|---|---|---|
| `fields` | 字段名称或匹配列表 | 本例只导出 `U`、`p`、`speed` |
| `excludeFields` | 可选列表 | 从选择中排除字段 |
| `internal` | 默认 `true` | 导出内部体网格 |
| `boundary` | 默认 `true` | 导出边界面 |
| `patches`、`excludePatches` | 可选列表 | 包含或排除指定边界 |
| `interpolate` | 默认 `false` | 是否添加插值到点上的数据 |
| `single` | 默认 `false` | 使用合并方式写出支持的网格部分 |
| `format` | 默认 `binary`；另有 `ascii` | 二进制更紧凑，ASCII 便于查看 |
| `legacy` | 默认 `false` | 使用旧式 VTK 格式而非 XML 格式 |
| `precision` | 系统默认 | ASCII 数字精度 |
| `directory` | 默认 `postProcessing/对象名` | 导出目录 |
| `width` | 默认 `8` | 文件名中步数的补零宽度 |
| `decompose` | 默认 `false` | 分解多面体，供相应读取器使用 |
| `writeIds` | 默认 `false` | 写出实体编号，辅助追踪原网格 |
| `selection` | 可选拓扑选择字典 | 导出子集 |
| `region` / `regions` | 区域名或列表 | 选择多区域网格 |

方腔的 `postProcessing/exportVTK` 中有 `.vtm` 汇总文件和 `.vtu` / `.vtp` 数据。优先打开 `.vtm`，它会组织内部网格和各个边界。文件名里的 `00000100` 是第 100 个时间步，物理时间为 0.5 s。

## 4. EnSight 格式

{{fo:01-cavity:exportEnsight}}

`ensightWrite` 同样接受字段选择、区域和输出频率等设置。常用的格式选项为 `format ascii` 或 `binary`，并可通过 `directory` 指定输出位置，按需要选择内部网格和边界。

| 参数 | 默认值 | 作用 |
|---|---|---|
| `fields`、`excludeFields` | 字段选择列表 | 指定输出和排除的字段 |
| `internal`、`boundary` | 均为 `true` | 内部网格与边界输出开关 |
| `nodeValues` | `false` | 输出插值到节点的数据 |
| `faceZones`、`patches`、`excludePatches` | 可选列表 | 选择面区及边界 |
| `format` | `binary` | 另可选 `ascii` |
| `width` | `8` | 数据目录的编号宽度 |
| `overwrite` | `false` | 是否覆盖已有导出目录 |
| `consecutive` | `false` | 使用连续输出编号 |
| `timeFormat`、`timePrecision` | `scientific`、`5` | 时间字符串格式与精度 |
| `selection` | 空字典 | 用拓扑选择动作限定网格子集 |

运行完成后打开：

```text
postProcessing/exportEnsight/01-cavity.case
```

`.case` 文件负责关联网格、字段和时间信息。分享 EnSight 数据时，把它与配套的 `data` 目录一起保留。

## 5. 保存数据库里已有的对象

`writeObjects` 用于将当前数据库中已有的对象写到磁盘。它适合保存某些由模型或前一个工具生成、但尚未自动输出的字段。

| 参数 | 用途 |
|---|---|
| `objects` | 要写出的对象名或匹配列表 |
| `writeOption` | 按对象的写出属性筛选，如 `autoWrite`、`noWrite`、`anyWrite` |
| `field` / `fields` | 可替代 `objects`，选择一个或多个字段 |
| `writeOption log` | 只列出匹配对象，便于先确认选择结果 |

`writeObjects` 与 `readFields` 方向相反：前者把内存中的对象写出去，后者把磁盘中的字段读进来。将它们和计算对象组合，就可以形成可重复使用的后处理字典。

## 6. 文件怎样选，数据怎样保持清楚

五个渐进操作是：读取一个场、读多个场后生成派生量、输出单元坐标和体积、导出指定字段到 VTK、导出完整时间序列到 EnSight。

研究内部场时选择内部网格，研究壁面载荷时选择对应 patch。每次导出只保留当前分析所需的字段，可以明显减小文件数量和传输大小。数值精度、单位、坐标方向与物理时间则应跟随结果一起保留。
