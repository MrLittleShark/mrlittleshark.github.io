流量、平均压力、压降都可以由面上的场得到。本课用后台阶 `pitzDaily` 算例，先统计入口与出口流量，再计算入口平均压力和进出口压降。

## 1. 运行后台阶算例

下载 `02-pitzDaily.zip`，解压后进入目录，运行 `bash Allrun`。`simpleFoam` 做 100 次稳态迭代，入口速度为 10 m/s。每 20 次迭代保存完整场，每 10 次迭代输出流量和力系数。

入口体积流量由 `phi` 求和：

{{fo:02-pitzDaily:inletFlux}}

`phi` 在这个不可压缩算例中是每个网格面的体积通量，已经包含面面积：

$$\phi_f=\mathbf U_f\cdot\mathbf S_f,\qquad Q=\sum_{f\in S}\phi_f.$$

所以使用 `operation sum`。入口面法向指向计算域外，而流体向域内流入，因此入口流量为负，出口流量为正。

## 2. 选择什么面

| 参数 | 可选值 / 默认 | 作用 |
|---|---|---|
| `regionType` | `patch`、`faceZone`、`sampledSurface`、`functionObjectSurface` | 选择已有边界、面区、采样面或功能对象生成的表面 |
| `name` | 区域名称 | 单个 patch / faceZone 的名称 |
| `names` | 名称列表或匹配表达式 | 合并处理多个目标面区，适用于支持该选择的区域类型 |
| `sampledSurfaceDict` | `sampledSurface` 时设置 | 写切面等采样表面的几何定义 |
| `fields` | 必填列表 | 例如 `(phi)`、`(p)`、`(T)` |
| `operation` | 必填 | 选择求和、平均、积分等 |
| `writeArea` | 默认 `false` | 把总面积写入结果文件 |
| `writeFields` | 默认 `false` | 是否同时导出面上的字段分布 |
| `surfaceFormat` | 导出面字段时设置 | 如 `vtk`，用于查看选区分布 |
| `postOperation` | 默认 `none`；另有 `mag`、`sqrt` | 对归约结果继续运算 |
| `weightField` / `weightFields` | 加权操作时填写 | 单个权重场或权重场列表 |
| `empty-surface` | `default`、`warn`、`ignore`、`strict` | 选区没有面时的处理策略 |

先查看 `constant/polyMesh/boundary` 中的真实边界名，再把对应名称填到 `name`。选择内部截面时，采用 `faceZone` 或采样表面。

## 3. 平均压力与流量为何采用不同操作

{{fo:02-pitzDaily:inletPressure}}

压力是“每个位置的值”，求面积平均时要给每个面乘面积，再除以总面积：

$$\overline p_A=\frac{\sum_f p_fA_f}{\sum_f A_f}.$$

常见的操作选择如下：

| 操作 | 作用 | 典型输入 |
|---|---|---|
| `sum` | 逐面相加 | 已经积分到单个面上的 `phi` |
| `sumMag` | 逐面取模后相加 | 统计双向穿越的总量 |
| `sumDirection`、`sumDirectionBalance` | 按指定 `direction` 区分方向求和 | 有明确主方向的通量分析 |
| `average`、`areaAverage` | 按面数平均、按面积平均 | 压力和温度常用面积平均 |
| `areaIntegrate` | $\sum f_fA_f$ | 热流密度积分成总热功率 |
| `areaNormalAverage`、`areaNormalIntegrate` | 与面法向点乘后平均或积分 | 从面速度计算法向输运 |
| `min`、`max` | 面上的极值 | 最高壁温、最大壁面剪切 |
| `CoV`、`uniformity` | 变异系数、均匀性指标 | 评价出口分布 |
| `weightedSum`、`weightedAverage` | 加权求和、平均 | 自定义权重统计 |
| `weightedAreaAverage`、`weightedAreaIntegrate`、`weightedUniformity` | 面积与权重共同参与 | 按通量或密度加权 |
| 对应的 `absWeighted...` | 使用权重的绝对值 | 流向变化时按通过量加权 |
| `none` | 只保留对象的其他处理 | 与面字段输出组合 |

通量的量纲可从 `phi` 文件的 `dimensions` 读取：不可压缩体积通量是 m³/s，可压缩求解器也可能使用 kg/s 的质量通量。先确定这一点，图表纵轴才能写对单位。

## 4. 自动输出进出口压降

`multiFieldValue` 对多个统计结果再计算。下面先分别得到两个面的平均压力，然后按“入口减出口”输出：

{{fo:02-pitzDaily:pressureDrop}}

`functions` 中的顺序决定减法的顺序。这里两个子对象都只输出一个标量平均压力，恰好逐项对应。

| `multiFieldValue` 参数 | 说明 |
|---|---|
| `operation` | `sum` / `add`、`subtract`、`divide`、`cmptDivide`、`min`、`max`、`average` |
| `functions` | 用命名子字典列出参加运算的功能对象 |
| 子对象的 `resultFields` | 可选择该对象已经公布的结果名称；省略时使用全部结果 |

压降输出位于 `postProcessing/pressureDrop/0/multiFieldValue.dat`。本例仍是运动压力差，乘以密度后得到 Pa。

## 5. 读数和下一步检查

![后台阶力系数与流量](/assets/science/functionobjects-forces.png)

100 次迭代时，入口流量为 −0.000254 m³/s，出口约为 0.0002541203 m³/s，相对差约 0.047%。图上的迭代变化提示我们，工程计算还可以继续迭代，观察流量差、压降和力是否一起趋于稳定。

由浅入深可以依次完成：单入口流量、入口与出口对比、面积平均压力、自动压降、带权重的平均。每次改变统计对象时，保留区域名称与量纲，结果之间就有明确的可比关系。
