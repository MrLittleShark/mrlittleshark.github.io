网格细化研究用于判断计算结果对空间分辨率有多敏感，时间步细化则检查时间分辨率。研究的对象应是实际关心的量，例如压降、阻力、峰值温度或某条速度剖面。不同量对网格的要求可以明显不同。

## 先选一个具体目标量

对于边长 0.1 m 的方腔，可以比较竖直中心线上的水平速度 $U_x$，也可以选取固定坐标的速度作为标量目标。为了方便演示，取

\[
Q=U_x(0.05,0.075,0.005)\,/\,U_{\mathrm{lid}}.
\]

坐标单位为 m，$U_{\mathrm{lid}}$ 为顶盖速度。三套网格都在同一物理位置采样，使用相同插值方法。这样比较的是同一个量，而不是编号相同却位置不同的单元。

如果关注壁面剪切力，目标量涉及速度梯度，通常比内部速度更依赖近壁网格。若关注湍流壁面函数，还应记录第一层高度和 $y^+$，使网格与近壁模型的使用方式保持一致。

## 建立三组有规律的网格

从刚解压的基础 `cavity` 建立三个副本。保留边长、顶盖速度、黏度、边界和离散格式，只修改 `system/blockMeshDict` 的单元数：

```foam
blocks
(
    hex (0 1 2 3 4 5 6 7) (40 40 1) simpleGrading (1 1 1)
);
```

这里 `(40 40 1)` 表示两个平面方向各 40 个单元，薄层方向 1 个单元。`simpleGrading (1 1 1)` 保持均匀间距。另两份分别改为 `(20 20 1)` 和 `(80 80 1)`，其余内容一致。

![方腔的系统网格细化](/assets/diagrams/core-refinement.svg)

| 网格 | 单元总数 | 平面间距 / m | 相邻网格尺度比 |
| --- | --- | --- | --- |
| 20 × 20 × 1 | 400 | 0.005 | — |
| 40 × 40 × 1 | 1600 | 0.0025 | 2 |
| 80 × 80 × 1 | 6400 | 0.00125 | 2 |

二维均匀细化每个方向加倍后，单元数增加四倍；三维则增加八倍。若还要减小时间步，计算总成本会进一步增加。因此应先在适当规模上设计好采样和比较方法。

每个副本执行：

```bash
blockMesh > log.blockMesh 2>&1
checkMesh -allGeometry -allTopology > log.checkMesh 2>&1
icoFoam > log.icoFoam 2>&1
```

三条命令分别生成网格、检查网格和计算流场。查看各日志后再进入下一组，重点记录实际单元数、质量指标和求解是否到达选定时刻。

## 把时间误差控制在比较需要的水平

如果三组网格都使用同一个较大的时间步，细网格的 Co 会更高，空间细化效果可能被时间误差掩盖。较清晰的安排是先在最细网格上做时间步研究，选出对目标量影响足够小的步长，再将这个步长用于三组网格。

例如可以在 80 × 80 网格上比较 0.0005、0.00025 和 0.000125 s，观察固定时刻的 $Q$。这些数值提供一组可运行的比较起点，最终选择取决于实际变化量和所需精度。

若目标是稳态方腔，三组计算都需要进入足够稳定的状态；若目标是启动过程，则比较同一个物理时刻的瞬态场。两种问题应分别确定结束时间。

## 在相同位置保存结果

向三个算例的 `controlDict/functions` 中加入同样的探针配置：

```foam
gridProbe
{
    type                 probes;
    libs                 (sampling);
    fields               (U);
    interpolationScheme  cellPoint;
    writeControl         timeStep;
    writeInterval        1;
    probeLocations       ((0.05 0.075 0.005));
}
```

`cellPoint` 指定基于单元和节点信息的插值，使网格不同但采样坐标相同。每步记录一个三分量速度，文件位于 `postProcessing/gridProbe`。使用同一个目标时刻的第一速度分量，再除以顶盖速度，即得到定义的 $Q$。

固定坐标的插值仍有数值误差，因此最好同时比较完整中心线剖面。ParaView 的 `Plot Over Line` 可以在三组数据中使用同样的起点、终点和采样点数，导出后画在一张图上。

## 两组差别与三组趋势

两组网格可以给出变化量，例如

\[
\delta_{21}=\frac{|Q_2-Q_1|}{|Q_1|}\times100\%.
\]

这里下标 1 表示细网格，2 表示中网格。若 $Q_1$ 接近零，使用绝对差或以顶盖速度等明确尺度归一化更合适。

三组网格还能观察差值是否缩小。假设网格间距满足 $h_2/h_1=h_3/h_2=r$，并且主要离散误差近似为 $Ch^p$，则可估算观察阶：

\[
p=\frac{\ln\left|\frac{Q_3-Q_2}{Q_2-Q_1}\right|}{\ln r}.
\]

在单调收敛、等比例细化且已进入主要误差规律稳定的区间时，可进一步进行 Richardson 外推：

\[
Q_{\mathrm{ext}}=Q_1+\frac{Q_1-Q_2}{r^p-1}.
\]

$Q_{\mathrm{ext}}$ 估计网格间距趋于零时的离散方程解。物理模型、边界条件或材料参数造成的误差仍需分别分析。

## 用一组数演示外推

假设某无量纲目标量在细、中、粗三组网格上依次为 1.01、1.04、1.16，且 $r=2$。这是用于演示计算方法的假设数据。相邻差值为 0.03 和 0.12，差值比为 4，所以 $p=2$，外推值为 1.00。

下面的 Python 代码增加了简单条件检查：

```python
from math import log

q1, q2, q3 = 1.01, 1.04, 1.16   # 细、中、粗网格
r = 2.0
d21, d32 = q2 - q1, q3 - q2

if r <= 1 or d21 * d32 <= 0:
    raise ValueError('本例公式要求等比例细化和同方向变化')

p = log(abs(d32 / d21)) / log(r)
if p <= 0:
    raise ValueError('细化后差值未缩小，需增加网格或检查其他误差')

q_ext = q1 + (q1 - q2) / (r**p - 1)
print(f'观察阶 p = {p:.4f}')
print(f'外推值 Q = {q_ext:.6f}')
```

`d21*d32>0` 表示目标量沿同一方向变化；`p>0` 表示细化后差值缩小。输出为观察阶 2.0000、外推值 1.000000。这些检查能排除部分明显不适用情形，实际还要确认迭代、时间和采样误差足够小。

## 为什么有时算不出合理的阶

当三个结果先增后减时，目标量出现振荡收敛；当相邻差值非常接近输出舍入误差时，对数比会十分敏感；网格质量随细化明显改变时，也可能同时改变离散误差结构。

遇到这些情况，可以增加一组网格，收紧线性容差，提高输出精度，或检查目标量是否恰好接近零。先绘制 $Q$ 对网格尺度的变化，再判断是否适合使用简单外推。

对一般非结构网格，可用 $h\propto N^{-1/d}$ 描述整体尺度，$d$ 是细化维度。但如果只加密局部区域，单元总数并不能完整反映关键位置的分辨率。此时应同时记录局部尺寸、第一层高度和几何逼近方式。

## 将结果整理成一张表

建议保存网格数、最大非正交角、时间步、目标量、相邻变化量和耗时。结论可以写成“中心线速度在 40 × 40 与 80 × 80 网格间最大变化为……，对应位置为……”。数值和位置来自本次结果，读者能够看出结论覆盖哪个量、哪组设置。

时间步研究同样可用三组序列分析。固定网格后将 $\Delta t$ 减半，比较同一物理时刻的场值，或者在足够长的统计区间比较均值、幅值和周期。湍流瞬态还存在统计采样误差，应延长采样时长或估计统计不确定度，再判断较小的网格差别是否有意义。

最后可以将方腔速度剖面与可靠的公开参考数据比较。网格细化检验数值离散的影响，参考数据比较则帮助评估整个建模与计算结果；二者结合，能更完整地说明计算精度。
