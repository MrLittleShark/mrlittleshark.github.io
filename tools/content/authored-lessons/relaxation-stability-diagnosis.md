松弛用于控制一次迭代中解的更新幅度。流动方程通常相互耦合：速度改变后，对流系数、湍流黏度和压力也随之改变。适当减缓更新，可以让这些量逐步协调，减少迭代振荡。

## 场松弛：保留一部分旧值

设旧迭代值为 $\phi^k$，本次求得的候选值为 $\phi^*$，场松弛取

\[
\phi^{k+1}=\phi^k+\alpha(\phi^*-\phi^k),
\qquad0<\alpha\le1.
\]

$\alpha$ 是松弛因子。例如旧值为 10，候选值为 14：取 $\alpha=1$，更新为 14；取 $\alpha=0.5$，更新为 12；取 $\alpha=0.2$，更新为 10.8。

较小因子使单次更新更温和，通常需要更多外迭代。对能充分收敛且解唯一的问题，各合理松弛因子应趋近同一个离散解；有限迭代次数下的结果则可能明显不同。

压力场松弛在 `system/fvSolution` 中可写为：

```foam
relaxationFactors
{
    fields
    {
        p 0.3;
    }
}
```

`fields` 表示对已求出的场做松弛。`p 0.3` 指定压力采用 0.3 的更新比例。它适用于在源码中调用压力场松弛的相应求解流程，如 SIMPLE 压力更新。

## 方程松弛：修改待求解的代数系统

方程松弛发生在求解之前。用已经对角占优的标量系统说明，其典型形式是把主对角系数 $a_P$ 改为 $a_P/\alpha$，并在右侧增加

\[
\left(\frac{1}{\alpha}-1\right)a_P\phi_P^k.
\]

这样保留旧解的影响，同时增强对角项。迭代收敛时，新旧解相同，增加的项在两侧抵消。OpenFOAM 的实际实现还会处理对角占优等细节，因此场松弛与方程松弛应分别理解。

速度和湍流方程常使用：

```foam
relaxationFactors
{
    fields
    {
        p 0.3;
    }
    equations
    {
        U             0.7;
        "(k|epsilon)" 0.7;
    }
}
```

`equations` 控制矩阵松弛；`U` 对应速度方程；正则键匹配 `k` 和 `epsilon` 两个场。使用 $k$–$\omega$ 模型时，可按实际场名改成 `"(k|omega)"`。

这组数值可以用于普通 SIMPLE 的参数比较。配套 `simpleFoam/pitzDaily` 采用 `consistent yes`，其原始方程松弛为 0.9。做本课练习时先运行原始配置，再单独调整其中一个因子，便于分析变化。

## 配置如何作用到求解器

`simpleFoam` 的动量求解代码按以下顺序操作：

```cpp
UEqn.relax();
fvOptions.constrain(UEqn);

if (simple.momentumPredictor())
{
    solve(UEqn == -fvc::grad(p));
    fvOptions.correct(U);
}
```

`UEqn.relax()` 读取速度方程的松弛设置，随后施加源项约束并求解。`pEqn.H` 中的压力松弛则在对应阶段处理压力场。字典条目与这些调用共同决定实际行为。

瞬态 PIMPLE 也可使用方程松弛。如果一个时间步内只做有限次外迭代，过强松弛可能使本时间步的耦合尚未充分收敛。比较瞬态设置时，应一起记录时间步、外校正次数和目标量变化。

## 一个可重复的松弛比较

进入 `simpleFoam/pitzDaily` 的三个独立副本，保留相同模型和网格，仅将速度方程松弛因子设为 0.5、0.7、0.9。可用以下命令修改一份副本：

```bash
foamDictionary system/fvSolution \
    -entry 'relaxationFactors/equations/U' -set 0.7

simpleFoam > log.simpleFoam 2>&1
foamLog log.simpleFoam
```

第一条只改 `U` 对应的因子。第二条运行并保存日志，第三条提取残差曲线。比较时记录到达相同收敛标准所需的迭代次数和耗时，并观察同一位置的速度或压差。

若 0.9 出现持续大幅振荡，而 0.7 平稳下降，可以保留 0.7 继续计算。若 0.5 收敛更慢但最终目标量相同，它主要改变了收敛路径。若不同因子长期收敛到不同状态，则还应检查迭代是否充分，或流动是否存在多稳态、非定常等特征。

## 发散时先定位最早的异常

发散通常经历一个发展过程：局部速度增大，通量和 Courant 数上升，模型变量出现异常，最后在除法、开方或矩阵运算时停止。完整日志能帮助确定最早变化发生在哪一步。

```bash
grep -nE 'Time =|Courant Number|continuity errors|bounding|FOAM FATAL|Floating point' \
    log.simpleFoam | tail -n 100
```

`grep -n` 同时显示原始行号，方便回到附近查看完整上下文。`bounding` 表示程序正在限制某些场值；它出现的频率和此前变量的变化，通常值得进一步检查。稳态 `simpleFoam` 的日志不一定包含 Courant 数，瞬态日志则可以用同样的筛选方式。

接着按异常的具体表现检查输入，而不是同时修改所有数值参数：

| 现象 | 优先检查 | 可以做的比较 |
| --- | --- | --- |
| 第一步就出现极大速度 | 几何尺寸、压力单位、初始场 | 核算特征速度与预期量级 |
| 高速集中在少数坏单元 | 网格质量、狭缝尺度 | 定位坏单元并改善局部网格 |
| 瞬态局部 Co 快速增长 | 时间步、速度增长、最小单元 | 减半时间步观察最早异常 |
| 湍流变量反复被限制 | 入口湍流量、壁面条件、格式 | 检查初值量级与边界搭配 |
| 残差有界但周期振荡 | 流动本身的非定常性、迭代强度 | 查看速度和受力时间或迭代记录 |
| 线性求解频繁到达上限 | 矩阵性质、预条件器、网格 | 比较合适的求解器与容差 |

## 例一：几何单位如何改变问题

假设希望模拟边长 0.1 m 的方腔，顶盖速度为 $1\,\mathrm{m/s}$，运动黏度为 $10^{-3}\,\mathrm{m^2/s}$。雷诺数为

\[
Re=\frac{UL}{\nu}=100.
\]

若网格错误地变成 100 m，雷诺数变成 $10^5$，流动物理和网格需求都会改变。此时调整松弛因子可能改变残差曲线，却没有恢复原来的问题。

运行 `checkMesh`，查看包围盒和总体积，并与几何尺寸核对：

```bash
checkMesh -allGeometry -allTopology > log.checkMesh 2>&1
grep -E 'Bounding box|Total volume|non-orthogonality|skewness|Failed' log.checkMesh
```

第一行执行完整几何和拓扑检查；第二行提取尺寸、体积和主要质量结果。若长度整体偏差 1000 倍，三维体积会偏差 $1000^3$ 倍，量级通常非常明显。

## 例二：初始场与边界突变

静止流体突然受到较高入口速度或大温差时，启动阶段会产生强梯度。可以根据真实工况设置合理初场，或给入口一个有限的上升时间。如果需要研究突然启动本身，则应使用足够小的初始时间步解析这一过程。

这两种处理对应不同的物理目标：渐增入口适合缓慢启动，阶跃入口适合研究快速瞬态。选择前先明确需要的过程，再观察峰值与时间步敏感性。

对于含源项的方程，还可估算源项时间尺度。例如 $dT/dt=-\lambda T$ 的响应时间为 $1/\lambda$；即使对流 Co 很小，较大的 $\lambda\Delta t$ 仍可能影响瞬态精度及耦合。

## 建立简短的排查记录

为每次修改留下四项就足够：修改对象、原值和新值、希望改变的现象、实际结果。例如“速度方程松弛 0.9 → 0.7，观察压力振荡；振荡减弱，中心速度最终相差 0.2%”。后面的百分比应来自实际计算。

修复后重看网格、残差、守恒和目标量。输入错误、数值迭代困难和物理非定常可能给出相似的日志表现，把观察与具体修改对应起来，排查会更快，也更容易积累可复用的经验。
