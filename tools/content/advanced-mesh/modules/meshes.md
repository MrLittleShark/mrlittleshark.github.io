## 根据计算问题选择网格方法

| 想处理的问题 | 方法 | 从哪里开始 |
| --- | --- | --- |
| 通道、方腔、复杂外形的初始网格 | 分块网格、贴体网格与局部加密 | [网格划分](/topics/meshing/) |
| 边界移动，周围网格随之拉伸或压缩 | 变形动网格 | [移动锥体](/read/?slug=advanced-mesh-01) |
| 物体大幅运动，局部网格独立移动 | 重叠网格 | [旋转物体与背景网格](/read/?slug=advanced-mesh-02) |
| 水面等流动结构移动，需要跟随加密 | 动态自适应加密 | [跟随水气界面加密](/read/?slug=advanced-mesh-03) |
| 叶轮持续转动，需要计算瞬态变化 | 旋转网格与 AMI | [二维搅拌槽](/read/?slug=advanced-mesh-04) |
| 用固定网格估计旋转设备的稳态流动 | MRF / SRF 旋转参考系 | [MRF](/read/?slug=advanced-mesh-05) · [SRF](/read/?slug=advanced-mesh-06) |

变形网格改变节点位置，动态加密改变单元数量，重叠网格在多套网格之间交换数据。MRF 和 SRF 则改变方程使用的参考系，网格保持固定。把这些区别与自己的物理问题对应起来，再进入相应课程。
