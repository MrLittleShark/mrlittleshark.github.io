snappyHexMesh 实战

本讲学习任务

①圆柱、混合弯管两个梯度算例，再加一个微柱阵列电极；②从 STL 到可用网格的脚本化流程（run_mesh.sh / Allrun）；③故意用一组会导致边界层覆盖率不足的参数，读日志自行定位并修好；④并行加网格：decomposePar → snappyHexMesh -parallel → reconstructParMesh；⑤surfaceCheck 与 STL 修补要点（微米级几何的单位陷阱）；⑥本方向的取舍：浓度边界层需要贴壁加密，但高纵横比的贴壁层会恶化接触线附近的曲率计算。

配套算例来自已有课程。下载解压后阅读其中的 README 与运行脚本，并在已加载 v2512 环境的 Linux 终端执行。本站未重新运行这些算例；原讲义中的本机路径需改为自己的实际路径。

配套算例位于原课程“10_snappyHexMesh操作与验证”目录。文中相对路径以该讲目录或已注明的算例目录为准。

本讲以圆柱凸起阵列的贴体网格和壁面层网格为主要案例。保留layers作为加层失败的诊断例，比较目标层数、实际覆盖率及质量阈值。原有失败结果见相关分析，成功加层结果与参数依据见本讲新增章节。

1 近壁网格与壁面层

壁面附近的速度、温度或浓度沿法向显著变化，壁面剪切与扩散通量的计算依赖该梯度。壁面层以较薄且方向有序的单元增加法向离散点，提高近壁变化的分辨率。

壁面层首先改变网格几何，其对梯度和通量精度的影响需通过求解验证。本讲三组仅生成网格并检查质量，图像用于评价形状、层数和覆盖范围。controlDict 中的 application 条目不代表已经求解，执行内容以 Allrun.sh 为准。

背景计算域的 x、z 范围均为 −0.002～0.002 m，y 范围为 0～0.004 m。各方向划分 16 个单元，共 4096 个，边长为 0.25 mm。posts.stl 的 x、z 范围均为 −1.1～1.1 mm，y 范围为 −0.2～1.5 mm，部分表面位于背景底面以下，需检查二者的交截关系。

2 从背景网格到贴体网格

snappyHexMesh 依次处理细化裁切、表面贴合与壁面层。细化阶段依据表面及保留点确定流体区域，贴体阶段移动边界点，加层阶段再调整近壁网格并挤出单元。前一阶段的质量影响后续操作。

本例启用切割、贴合和加层三个阶段。表面细化等级为 1，相关区域边长约减半，不同等级间保留三层过渡单元。locationInMesh=(0.0018 0.0038 0.0018) 位于外部流体区，用于选择保留的连通区域。

castellatedMesh true;
snap true;
addLayers true;
refinementSurfaces
{
    posts
    {
        level (1 1);
        patchInfo { type wall; }
    }
}
locationInMesh (0.0018 0.0038 0.0018);

posts.stl 以 triSurfaceMesh 类型读入，几何对象命名为 posts，后续细化条目引用该名称。表面文件、对象名、最终边界和加层选择表达式应对应一致。预期表面未被选中时，应先修正名称，再调整层厚参数。

本例启用隐式特征识别，关闭显式特征贴合。顶点通过平滑、位移求解及松弛逐步接近表面，过大位移可能降低邻近单元质量。应分别检查凸起顶部、侧壁、底部交线和邻近单元，综合评价贴合程度。

3 层厚参数及其几何含义

层厚配置需同时明确层数、厚度比和长度基准。relativeSizes=true 时厚度相对局部网格定义，finalLayerThickness 表示最外层厚度。expansionRatio 控制层间增长，通常使外层厚于第一层。

relativeSizes true;
layers
{
    "posts.*" { nSurfaceLayers 2; }
}
expansionRatio 1.2;
finalLayerThickness 0.3;
minThickness 0.05;

若第一层厚度为 h₁，相邻层比为 r，则第 k 层厚度为 hₖ=h₁r^(k−1)，总厚度为各层厚度之和。r 不等于一时，H=h₁(r^N−1)/(r−1)。已知最外层厚度 hN 时，先计算 h₁=hN/r^(N−1)，再求总厚度。两种输入定义不能直接互换，否则会把第一层或整体厚度估计错误。

例如三层单元的第一层厚度为 0.02 mm，增长比为 1.2，则各层厚度分别为 0.020、0.024、0.0288 mm，总厚度为 0.0728 mm。若两侧壁面之间的间隙仅为 0.10 mm，按同样设置从两侧各生成一组层，总需求厚度为 0.1456 mm，超过可用空间。此时挤出可能被压缩、截断或取消，问题来自几何空间与厚度要求不相容。

minThickness 给出允许保留的最小厚度尺度，过薄的层会被舍弃。控制层厚与中轴距离比例的参数用于限制狭窄区的挤出，表面法向平滑则减少相邻挤出方向的剧烈变化。调整这些参数前，需要知道局部失败发生于尖角、凹角、薄缝还是平坦区域。不同几何位置对应的限制不同，一组参数不能仅按数值大小统一增加。

相对层厚还需结合表面附近实际网格尺寸解释。若仅按本例一级细化后的名义边长 0.125 mm 估算，基准最外层厚度为 0.0375 mm。目标为两层、增长比为一点二时，第一层约为 0.03125 mm，总厚度约为 0.06875 mm。

减小最外层参数至零点一五后，对应名义最外层厚度为 0.01875 mm，第一层约为 0.015625 mm，总厚度约为 0.034375 mm。这些数值属于按输入推算的目标尺寸，实际结果仍需从层字段读取。

目标层数改为三而最外层相对厚度保持不变时，最内层随层数增加而减薄，总厚度则改变。按同样名义尺寸计算，第一层约为 0.0260417 mm，三层总厚度约为 0.0947917 mm。因此“增加层数”同时影响近壁第一层和总体挤出厚度，并非仅在原网格外再附加一个厚度相同的单元。比较不同目标层数之前，应先完成这一几何换算，判断可用空间是否仍满足要求。

对于壁面法向扩散，可用近壁单元中心与边界之间的差分估计梯度。若边界值为定值，第一单元中心距离减小后，相同场值差对应更大的梯度；这并不意味着通量一定增大，因为重新求解后单元值也会改变。比较网格影响时必须重求场，并使用各组真实中心到边界距离。仅将旧场的差值除以新的层厚，会混用不同网格和不同离散方程。

4 加层失败的保留诊断例

layers 保留未成功生成壁面层的配置，用于分析失败原因。原试算调整厚度和层数后仍为 9066 个单元，表明挤出层在质量检查后被撤回。本讲采用 layers、posts_snap_reference 和 posts_layers_success 三组进行对照。

在layers目录执行Allrun.sh后，读取log.snappyHexMesh中的Writing 0 faces inside added layer及Layer mesh信息。该日志表明生成了贴体网格，但没有保留壁面层。再比较成功例中的新增层单元、实际层数和覆盖率，定位差异来自哪些质量与厚度设置。

5 绝对体积阈值与几何尺度

旧例 minVol=1e−13 m³ 高于部分毫米尺度薄层的正面锥体积，导致挤出撤回。成功例取 minVol=1e−18 m³、两层及最外层相对厚度 0.15，继续检查负体积。绝对质量阈值须与几何单位及最小尺寸匹配。

常规checkMesh检查通过后，还需读取扩展几何检查。成功例存在凹单元，相关数量及位置见本讲后续分析；常规检查通过不能表述为所有几何项目均通过。网格用于具体流动求解之前，还需检查这些单元对目标梯度及求解稳定性的影响。

6 壁面层失败的定位方法

应先确认目标 patch 是否存在，再检查加层选择是否命中该 patch，最后分析挤出和质量拒绝原因。这一顺序对应“对象、操作、保留结果”三个具体问题。若连目标对象都没有选中，继续减小层厚缺乏依据；若对象已被选中但层在质量检查后删除，则需要分析局部网格及限制条目。

本例 writeFlags 中包含 layerSets 和 layerFields，可输出实际层数、总体厚度以及实际厚度与目标厚度之比等信息。查看这些字段时，要确认其对应最终生成的网格，并结合表面位置分析。局部层数为零的位置需要与几何交线、法向变化和背景分辨率一一核对，单独增加迭代次数不能替代这一步。

对于尖锐交线，相邻表面的挤出方向差异可能使单元挤压或交叉；对于狭窄区域，两侧层可能相互接近；对于粗背景网格，近壁单元缺少足够位移空间，表面贴合误差也可能较大。上述机制提供检查方向，当前日志中的零新增层本身并不足以唯一确定原因，应通过单项修改建立对应证据。

进一步试验可先保留基准目录，在副本中确认目标 patch 的匹配，再只调整一个几何或层厚条件。每组记录目标层数、实际层数分布、覆盖面积、最小单元体积及非正交角。若修改后网格总数增加，仍需从层字段检查增加部分是否来自壁面层，而非表面细化。这样才能把参数变化与具体网格结果联系起来。

7 网格质量与流动分辨率

非正交角反映单元中心连线与公共面法向的偏离，偏斜度反映面中心相对于插值位置的偏移。这些几何偏差会影响扩散梯度和面值插值，并增加修正项或线性迭代的负担。实际网格的指标与背景网格不同，是表面贴合和局部细化产生几何变化的结果。

壁面层单元的长宽比可能较大，但其长方向通常沿壁面、薄方向沿主要梯度。评价此类单元时，须同时考虑方向与求解变量的变化。对于明显法向梯度，均匀增加所有方向的单元可能耗费较多计算量；沿法向合理布置层数更有针对性。对于三维复杂分离流动，切向分辨率也必须满足要求，不能只细化第一层。

本讲尚未给定壁面摩擦速度，因此不能由层厚直接确定 y⁺。应用到湍流问题时，需要根据目标壁面处理、运动黏度和摩擦速度估计第一单元中心距离，并在求解后用实际壁面量复核。层流传热或扩散问题则应比较温度梯度、浓度梯度或总通量随网格变化的结果。网格检查提供后续求解的几何条件，最终分辨率仍由所研究的场量及误差要求决定。

对保留的失败例，完整表述应包括：背景网格、表面细化等级、启用阶段、目标加层设置、最终单元数、质量指标，以及尚未生成壁面层这一事实。这样的记录既能复现现有网格，也能明确下一步需要验证的设置。

10 网格分辨率与壁面梯度

圆柱凸起阵列包含柱侧曲面、柱顶边缘、柱脚与柱间通道。流体绕过凸起时，速度梯度和压力梯度会随位置变化。对于无滑移壁面，壁面速度为零，近壁单元的速度用于近似壁面法向导数。若第一单元中心距壁面过大，即使远离壁面的单元数量很多，壁面应力仍可能缺乏足够分辨率。因此，近壁网格设计应先说明需要计算的梯度和积分量，再确定层厚与层数。

本节采用4 mm×4 mm×4 mm的背景域，底部圆柱凸起由posts.stl给出。圆柱半径0.3 mm，露出底面的高度1.5 mm。背景网格为16×16×16，单元边长0.25 mm；表面采用一级细化，对应局部边长约0.125 mm。几何与背景网格均使用米作为内部单位。surfaceCheck与checkMesh的包围盒是核对长度单位的直接依据。

posts_snap_reference和posts_layers_success使用相同的几何及细化设置。前者完成裁切和贴体，后者继续生成壁面层。这一对照用于区分表面贴合与法向加密的作用。两组均为纯网格案例，不求解速度、压力或能量方程；controlDict中的时间对象服务于网格程序，不表示已经计算了一段物理流动。

11 层厚参数的含义与计算

设最靠近壁面的第一层厚度为h₁，相邻层厚增长率为r，目标层数为N，则第k层厚度hₖ=h₁r^(k−1)，总层厚H=h₁(1−rᴺ)/(1−r)。当r=1时，H=Nh₁。给定最外层厚度hN后，有h₁=hN/r^(N−1)。这些关系用于检查参数数量级，并不替代生成后的实际厚度测量。

本例relativeSizes为true，finalLayerThickness=0.15表示最外一层厚度与层外未变形单元尺寸的比值。取局部尺寸125 μm，得到hN=18.75 μm。目标N=2、r=1.2时，h₁=15.625 μm，H=34.375 μm。

将finalLayerThickness误认为总厚度，会使首层距离估计发生系统偏差。minThickness同样为相对值，控制局部允许生成的最小层厚条件。

实际近壁单元并非处处等厚。柱顶转角处法向发生变化，柱脚附近还受到相邻边界约束，网格移动需同时满足面权重、体积比和质量限制。当局部条件不能满足要求时，层可能减薄、终止或完全撤回。0/nSurfaceLayers与0/thickness分别记录实际层数和总层厚，不能仅用字典中的目标值替代。

12 毫米尺度下的绝对质量阈值

旧例的关键问题在于minVol=1e−13。该参数定义面锥体积的绝对下限，单位m³。长度缩小十倍，面积缩小一百倍，体积缩小一千倍，因此绝对体积阈值必须结合实际几何尺寸判断。它与无量纲的非正交角、偏斜度或体积比具有不同的尺度性质。

旧日志显示，薄层挤出后大量面锥体积小于阈值，随后挤出被撤回，最终没有新增层单元。只调整目标层数或减小层厚不能解决这一问题，减薄甚至可能使面锥体积更小。新例将minVol设为正值1e−18，并保留四面体质量、非正交、面权重和相邻体积比等限制。该设置仍排除负体积，没有使用负阈值绕过检查。

运行按blockMesh、surfaceCheck、snappyHexMesh -overwrite、checkMesh顺序进行。每条命令的日志单独保存。snappyHexMesh日志用于观察阶段和层生成过程，checkMesh日志用于检查最终网格。分析失败时，应从最先违反的质量条件定位，再解释层为何被撤回，而不应只查看最后的End。

13 实际生成结果

不加层网格有9066个单元。成功例有10538个单元，新增1472个层单元。posts边界共有852个目标面，其中704面有两层、64面有一层、84面无层。按面数统计，覆盖率为768/852=90.14%，平均层数为1.7277。该覆盖率的分母是壁面数，并非面积。

全目标壁面的总层厚均值为27.49 μm；仅在已覆盖面上计算时，均值为30.50 μm。已覆盖位置的总层厚约为6.20–34.37 μm。未生成层的位置会把全壁面均值降低，因此两种平均值必须分别说明。进一步研究还应采用面积加权统计，并报告层终止位置与关注流动区域之间的关系。

配图使用生成网格的points和faces计算z=−0.8 mm截面交线，展示柱侧及柱顶附近的实际单元形状。全局图用于确定位置，局部放大图用于识别薄层。查看云图或层数直方图时，应同时保留几何位置，避免把全局平均值误认为每一处都达到同样的分辨率。

14 质量检查与后续判断

成功例最小单元体积8.33×10⁻¹⁴ m³，最大非正交角28.19°，最大偏斜度0.586，标准checkMesh通过。启用-allGeometry和-allTopology后，报告374个凹形多面体；不加层对照为278个。扩展检查未通过的这一项在完整日志和数值记录中保留。

较厚层方案的凹形单元为432个，减薄后降至374个；显式特征边试算没有同时改善层覆盖和非凸问题，因此未作为最终配置。这里的比较说明参数调整存在相互影响：增加层覆盖、提高几何贴合度和减少非凸单元未必同步。正式流动分析应定位这些单元，判断其是否影响壁面梯度、局部通量和最终积分量，再通过网格与格式研究确认。

本节训练以成功加层及其对照为主，旧0层输入作为绝对尺度错误的诊断材料。提交结果应包含参数推导、完整运行日志、实际层数分布、截面图和扩展质量检查。若将网格继续用于流动问题，应补充首层距离与所需梯度尺度的关系，并报告目标输出随网格改动的变化。
