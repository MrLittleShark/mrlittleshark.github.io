01

环境与首次上手

配置运行环境，执行算例并分析日志。

第 01—04 讲
01

环境与 Linux

CFD 完整链条：几何 → 网格 → 物理模型 → 离散 → 求解 → 后处理 → 验证；以“微电极上的一个析氢气泡”为例，说明各阶段的输入、输出及检查方法；②OpenFOAM 是什么，三大分支（.org / .com / foam-extend）的差异与字典不兼容问题；本课程统一用 v2512（.com）的理由；③安装：WSL2+Ubuntu / 原生 Linux / Docker 三条路径，选择一种方式完成安装与验证；④环境变量与 bashrc：$WM_PROJECT_DIR、$FOAM_RUN、$FOAM_TUTORIALS、$FOAM_SOLVERS、$FOAM_SRC；⑤Linux 必备命令：ls / cd / cp / rm / find / grep / tail -f / vim 基本操作、管道与重定向；⑥源码目录组织与一个 application 的标准结构（Make/files、Make/options）。

90 分钟02

方腔流动与 ParaView

cavity 算例全流程：blockMesh → icoFoam → paraFoam，先执行基准算例并记录输出，再分析参数含义；②日志与后台运行习惯：solver > log 2>&1 &、tail -f log、foamMonitor 画残差；③ParaView 基础操作：界面布局、鼠标操作、场变量显示、Slice / Glyph / Plot Over Line / Stream Tracer；④中途停止与续算（stopAt writeNow / startFrom latestTime）；⑤算例目录清理（foamCleanTutorials、foamListTimes -rm）。

90 分钟03

算例目录与量纲

三目录职责分工：初始与边界场 / 物性与网格 / 数值控制；②量纲向量 [kg m s K mol A cd] 的读法与常见错误（顺带指出浓度用 mol/m³ 时第五位 mol 的写法）；③constant：transportProperties、polyMesh、boundary 文件与 patch 类型；④system：controlDict（时间控制、写盘、functions）、fvSchemes、fvSolution 各管什么；⑤0 目录场文件结构：FoamFile header 中的 class（volScalarField / volVectorField）、dimensions、internalField、boundaryField；⑥重点提示：不可压单相求解器中的 p 是运动学压力 p/ρ，单位 m²/s²；而 interFoam 等两相求解器中的 p、p_rgh 是真实压力，单位 Pa——同一个名字，两套单位。

90 分钟04

日志阅读与排错

屏幕输出逐行解读：Time、Courant Number、各方程初/终残差、continuity errors、ExecutionTime/ClockTime；②高频报错诊断路径：keyword not found、inconsistent dimensions、floating point exception、Maximum number of iterations exceeded、cannot find file；③字典通用语法：#include、#includeEtc、宏替换 $、正则表达式匹配 patch、注释与 #calc；④自助查询三件套：solver -help、故意写非法关键词让程序列出全部合法选项、在 $FOAM_TUTORIALS 与源码中 grep 检索。

90 分钟
02

典型算例与物理分析

比较两相流与绕流的模型设置和结果。

第 05—06 讲
05

溃坝与上升气泡

interFoam 与 VOF 方法的基本思路；②新出现的字典：g、两相 transportProperties（含表面张力系数 sigma）、turbulenceProperties（laminar）；③新出现的场：alpha.water、p_rgh 与 p 的区别与换算；④setFields + setFieldsDict 做初始液柱；⑤adjustableRunTime、maxCo 与 maxAlphaCo 的联动；⑥ParaView 中用 Contour(alpha=0.5) 重构自由面；⑦延伸：用 sphereToCell 放一个气泡——同一套设置从“水柱倒塌”变成“气泡上升”。

90 分钟06

圆柱绕流

同一几何在 Re=10 / 40 / 100 / 200 下的设置差异与结果差异（附着流 → 对称回流泡 → 卡门涡街）；②多块 blockMesh 网格与近壁加密；③forceCoeffs functionObject 计算 Cd、Cl，FFT 求 Strouhal 数；④何时必须引入湍流模型：判据与代价，并说明本课题尺度下为什么基本不需要；⑤时间步、离散格式对涡街形态的影响（同一 Re 下的多组对照）。

90 分钟
03

网格生成与质量

学习结构网格、复杂几何与边界分区。

第 07—11 讲
07

网格质量

网格类型：结构化 / 非结构化 / 多面体 / 切割体，各自的适用场景；②质量指标的几何定义与其对离散精度的作用机制：非正交度、偏斜度、纵横比、体积比、面翘曲、负体积；③checkMesh 输出逐项解读与可接受阈值（含 -allGeometry -allTopology）；④质量指标与数值设置的耦合：非正交度大 → 需开非正交修正 → 迭代变多 → 变慢；⑤界面问题的特殊要求：界面扫过的区域要用尺寸均匀、接近立方的单元，并保证气泡半径方向有足够的网格数（具体多少，第 17 讲自己测）。

90 分钟08

blockMesh 与轴对称

blockMeshDict 结构：scale、vertices、blocks、edges、boundary、mergePatchPairs；②hex 顶点顺序与右手法则（写反的后果与识别方法）；③simpleGrading / edgeGrading / multi-grading 做加密，以及“哪里不能加密”；④弧线边（arc / spline）与曲面块；⑤patch 类型：wall / patch / empty / symmetry / wedge；二维算例的 empty 与轴对称算例的 wedge；⑥多块拼接与共节点检查；把电极面与绝缘基底分成两个 patch。

90 分钟09

snappyHexMesh 原理

前提：背景网格 blockMesh + 水密 STL + surfaceFeatures 特征线提取；②castellation：refinementSurfaces / refinementRegions / 细化层级 / locationInMesh；③snap：贴体迭代、特征线捕捉、nSmoothPatch / tolerance / nSolveIter；④addLayers：expansionRatio、finalLayerThickness、minThickness、relativeSizes 与覆盖率；⑤meshQualityControls 在三个阶段中的作用。

90 分钟10

snappyHexMesh 实战

圆柱、混合弯管两个梯度算例，再加一个微柱阵列电极；②从 STL 到可用网格的脚本化流程（run_mesh.sh / Allrun）；③故意用一组会导致边界层覆盖率不足的参数，读日志自行定位并修好；④并行加网格：decomposePar → snappyHexMesh -parallel → reconstructParMesh；⑤surfaceCheck 与 STL 修补要点（微米级几何的单位陷阱）；⑥本方向的取舍：浓度边界层需要贴壁加密，但高纵横比的贴壁层会恶化接触线附近的曲率计算。

90 分钟11

网格转换与边界分区

网格转换：fluentMeshToFoam、gmshToFoam、ideasUnvToFoam、cfMesh 简介与常见转换失败原因；②操作工具：transformPoints、mirrorMesh、mergeMeshes、refineMesh、createPatch、renumberMesh；③topoSet / setSet：按几何形状（box、sphere、cylinder）选取 cellSet / faceSet，并转为 cellZone；④用 faceSet + createPatch 从一整块壁面上切出电极面（或多个成核位点）；⑤CAD 建模要点：水密性、特征线保留、STL 导出精度与单位（微米级几何尤其要核对单位）。

90 分钟
04

数值方法与验证

理解离散、耦合与误差，验证静止气泡。

第 12—17 讲
12

有限体积与离散格式

通用输运方程与控制体积分、高斯定理；②对流项格式族：upwind / linear / linearUpwind / limitedLinear / vanLeer / TVD 限制器；③梯度格式：Gauss linear、leastSquares、cellLimited / faceLimited；④拉普拉斯项、snGrad 与非正交修正（corrected / limited / orthogonal）；⑤精度—有界性—稳定性的三角权衡；⑥fvSchemes 每一条目与方程中每一项的一一对应。

90 分钟13

时间步与线性求解器

CFL 数的定义、物理含义与显式/隐式稳定性差异；maxCo、adjustTimeStep 与写盘时刻对齐；②毛细时间步约束（Brackbill）：Δt ≲ √(ρ̄Δx³/(2πσ))，网格越细越苛刻；与 CFL 限制的比较；③线性方程组求解：PCG / PBiCGStab / GAMG / smoothSolver、预条件子与光顺器；④tolerance 与 relTol 的区别，收敛准则怎么定才不浪费机时；⑤澄清概念：solver（求解器应用）≠ linear solver（线性方程组求解器）。

90 分钟14

压力速度耦合

不可压方程组的“压力没有独立方程”问题从何而来；②SIMPLE：稳态、松弛因子、外迭代；③PISO：瞬态、nCorrectors、时间步受 CFL 限制；④PIMPLE：大时间步瞬态、nOuterCorrectors、残差控制 residualControl；⑤nNonOrthogonalCorrectors 与网格非正交度的定量关系；⑥两相求解器中的 PIMPLE：p_rgh 方程如何把表面张力和重力放进面通量（平衡力离散）；momentumPredictor 为何常关。

90 分钟15

残差与边界条件

初始残差 / 最终残差 / 连续性误差的定义；“收敛”的双重判据：残差下降 + 物理监控量稳定 + 守恒量闭合；假收敛与残差平台的识别；②边界条件按数学类型归类：Dirichlet / Neumann / Robin，再映射到 OpenFOAM 名称（fixedValue / fixedGradient / mixed）；③常用边界条件族：zeroGradient、inletOutlet、totalPressure、noSlip、slip、symmetry、wedge；④两相专用：p_rgh 壁面的 fixedFluxPressure、开放顶面的 prghPressure / prghTotalPressure、alpha 的 inletOutlet、接触角条件 constantAlphaContactAngle / dynamicAlphaContactAngle；⑤把电化学条件翻译成边界：Faraday 定律 → 浓度的 fixedGradient（通量边界）；电极动力学 → 电势的 mixed（Robin）；⑥初始条件与种子气泡；mapFields 做初场映射。

90 分钟16

格式误差实验

一维纯对流（scalarTransportFoam）：不同对流格式的数值耗散与色散，与行波解析解对比；②二维拉普拉斯方程：单元类型与梯度格式对梯度精度的影响；③非正交方腔：非正交修正开/关的对照，以及配套的 fvSolution 设置；④高 Péclet 数对流—扩散：用溶解气体的真实扩散系数重复实验①，观察负浓度与过冲从何而来；⑤误差—耗时权衡曲线的做法。

90 分钟17

静止气泡与寄生流

Young–Laplace 解析解：轴对称静止气泡的压力跳跃 Δp = 2σ/R；寄生流的来源（曲率误差 + 力不平衡）；②用第 8 讲自己画的轴对称网格 + setFields 放一个静止气泡；③分别用 interFoam（MULES + cAlpha）与 interIsoFoam（几何 VOF）求解，对比压力跳跃误差与寄生流最大速度；④时间步超过毛细约束时的失稳现象（验证第 13 讲的估算）；⑤网格收敛性：Laplace 压力误差与寄生流速度随“每个半径的网格数”的变化；把寄生流速度与课题中的物理速度（上升速度、Marangoni 流速）比较。

90 分钟
05

并行与定量后处理

提高计算效率，提取可比较的气泡特征量。

第 18—19 讲
18

并行计算

lscpu 查硬件；物理核 vs 逻辑核；②decomposeParDict：simple / hierarchical / scotch / manual 及各自适用场景；③decomposePar → mpirun -np N solver -parallel → reconstructPar 全流程；④并行日志、并行后处理（不重构直接读 processor* 目录）；⑤强/弱扩展性测试、“每核网格量”经验值、过度分区与 I/O 瓶颈。

90 分钟19

气泡特征量与后处理

运行时后处理 functionObjects：probes、volFieldValue、surfaceFieldValue、fieldMinMax、surfaces、residuals、writeObjects；②postProcess 工具的事后处理与 -func 用法；③线/面/等值面采样，配 gnuplot 或 Python(matplotlib) 出图；④气泡专用量：气泡体积与等效半径（对 1−alpha 体积分）、质心高度与上升速度、接触线半径与表观接触角、电极面平均浓度梯度（→ Sherwood 数）与电流密度；⑤foamToVTK / foamToEnsight 与第三方软件对接。

90 分钟
06

多相流与传质

理解 VOF、润湿、扩散与自定义边界。

第 20—24 讲
20

VOF 与接触角

多相流分类：自由面 / 弥散相 / 欧拉—欧拉 / 欧拉—拉格朗日；电解体系从单气泡到气泡流的尺度谱；②VOF 方程、界面压缩 cAlpha 与 MULES 限制器；几何 VOF（interIsoFoam：isoAlpha / plicRDF 界面重构）；③表面张力：CSF 模型、由 alpha 梯度算曲率、寄生流的成因与缓解（曲率平滑、几何重构、足够分辨率）；④接触角：静态接触角、滞后（前进角 / 后退角）与 dynamicAlphaContactAngle；接触线钉扎；接触角是从哪一相量起的；⑤无量纲数判定：Bo、Ca、We、Oh、Re 在电解气泡尺度下的量级，判断谁主导；⑥实操：capillaryRise 算例，并回收第 5 讲的上升气泡（解释当时看到的寄生流与形状问题）。

90 分钟21

标量扩散与通量边界

析气的物质链：电流 → Faraday 定律产气 → 溶解气体在电极附近过饱和 → 向气泡扩散；②溶解气体输运方程；scalarTransportFoam 与 scalarTransport 函数对象的用法；③电极通量边界：fixedGradient 的梯度 = j/(zFD)，法向与符号约定；④Henry 定律、饱和浓度与过饱和度的定义；⑤浓度边界层：Sc 数、边界层厚度与所需网格；⑥解析解验证：恒通量半无限扩散的表面浓度 c(0,t) = 2N√(t/(πD))。

90 分钟22

稳态扩散与混合边界

电解液中的电荷守恒：∇·(κ∇φ) = 0（均匀电解液、忽略浓差时）；一次 / 二次电流分布的区别与 Wagner 数；②用 laplacianFoam 求电势：电极、对电极与绝缘壁的边界；③气泡作为绝缘体：用 snappyHexMesh 把一个静止气泡从计算域里“挖掉”，看电流线绕行与电极电流密度的重新分布；④电极动力学：Butler–Volmer 及其线性化；线性化后是 Robin 条件，用 mixed 边界实现，非线性形式留到第 24 讲；⑤有效电导率：VOF 中电导率随 alpha 变化的写法（线性混合、Bruggeman）与后续耦合思路。

90 分钟23

源项与自适应加密

fvOptions 源项机制：semiImplicitSource、buoyancyForce 等；selectionMode 与 cellZone；②配合 topoSet 在指定区域施加源项：电极附近的焦耳热、种子气泡区的等效产气、浓度或温度引起的自然对流；③自适应网格加密 dynamicRefineFvMesh：沿界面加密的判据、代价与限制（官方实现只支持三维）；④动网格与运动物体的概念地图（solidBody、六自由度、AMI、overset），说明本课题为何基本用不到。

90 分钟24

codeStream 与 coded 边界

codeStream 机制与运行时编译原理；②用 codeStream 做初始化：给定体积与接触角的球冠种子气泡、多个成核位点；③时变边界：先用 uniformFixedGradient + Function1（如方波）实现脉冲电流，再对比 coded 写法——能不写代码就不写；④codedMixed：非线性 Butler–Volmer 电极边界（回收第 22 讲）；⑤codedSource（fvOptions）：以给定温度分布下的 Marangoni 力为例，在动量方程里加自定义源项；⑥运行时编译的报错定位与调试方法。

90 分钟
07

电极气泡与结课项目

建立守恒模型，研究生长与脱落。

第 25—28 讲
25

自定义 myInterFoam

OpenFOAM 的 C++ 面向对象设计与场运算符重载；方程怎么写成接近数学形式的代码；②fvm 与 fvc 的本质区别：隐式装配矩阵 vs 显式求值；③逐行读懂 icoFoam 主程序；④读 interFoam：alphaEqn、UEqn、pEqn 中表面张力与重力如何进入面通量（接回第 14 讲的平衡力离散）；⑤wmake 编译系统：Make/files、Make/options、$FOAM_USER_APPBIN；⑥复制并改造：myInterFoam 加一个溶解气体浓度方程（先不处理界面跳跃）；调试手段。

90 分钟26

电极气泡的产气与生长

电解气泡的物理图景与时间尺度：成核（连续介质模型无法解析，用种子气泡代替）→ 生长 → 脱落 → 上升；②路线 A 等效注气：把电极中心一小块设为气体入口，流量按 Faraday 定律 × 析气效率换算——不改代码，专注脱落力学；③路线 B 溶解气体 + 界面传质：连续组分传输（CST）方法、Henry 定律跳跃、界面质量通量作为 alpha 方程与连续性方程的源项（在第 25 讲 myInterFoam 上实现）；④两条路线的精度、代价与各自能回答的问题；⑤时间尺度分离的对策：加大电流密度或过饱和度以加速生长、二维轴对称、远场放粗，以及这些做法各自的代价；⑥验证：扩散控制生长 R ∝ t^1/2（Scriven 解）与恒电流产气控制 R ∝ t^1/3；网格收敛性。

90 分钟27

电势耦合与气泡脱落

脱落力平衡：浮力、接触线表面张力、接触压力、曳力、Marangoni 力；Fritz 公式与接触角的线性关系；②接触角滞后与接触线钉扎对脱落直径的影响；③Marangoni 效应：热毛细与溶质毛细的来源与方向；标准 CSF 只含法向力、不含切向的 ∇sσ，必须自己加（回收第 24 讲）；④多气泡：多个成核位点、聚并诱导脱落、电极覆盖率与电流遮蔽的双向耦合（回收第 22 讲）；必须三维，靠并行与自适应加密（回收第 18、23 讲）；⑤工具生态：OpenFOAM 原生 + 自研、TwoPhaseFlow 等开源框架、CSECGEFoam、Basilisk、COMSOL，以及电解槽尺度的欧拉—欧拉方法；⑥为自己的课题做方案选型。
