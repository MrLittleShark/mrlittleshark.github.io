## 从目录管理内容

打开[网站管理](/admin/)，使用有管理权限的 GitHub 账号登录。左侧是网站目录，右侧是所选目录及其子目录中的内容。

### 添加模块和子模块

1. 点击左侧 **添加模块**，填写名称，例如“传热与传质”。
2. 要建立子模块，先选中上级目录，再点击 **添加子模块**。
3. 填写简介和排序。排序值越小，位置越靠前。
4. 保存后，网站导航和对应的内容目录会更新。新模块的入口地址由系统生成，保持默认即可。

**编辑目录**可以改名、改简介、调整排序和上级目录。取消“显示在导航中”会隐藏该目录及其子目录的导航入口，文章仍保留原有公开地址。

### 在目录中新建文章

1. 在左侧选中目标目录，点击 **新建内容**。
2. 填写标题、摘要和正文。右侧的 **所在位置** 已选中当前目录。
3. 需要同时放在多个位置时，再勾选其他目录。例如，同一篇教程可以同时放在“系统学习／物理模型”和“专题学习／湍流”。
4. 根据用途选择内容类型：课程单元、分享文章、下载资料、工具教程、公告或作业等。
5. 点击 **保存** 保留草稿，或点击 **保存并发布** 公开内容。

目录位置和内容类型分别设置。一篇文章无论放在多少个位置，都使用同一份正文和同一个地址。

### 移动、删除和恢复

内容表格的 **所在位置** 一列会列出所有完整路径。点击 **移动** 可以增减归属目录，确认后保存；正文、附件和文章地址保持原样。

删除目录时会列出涉及的子目录和文章数量。确认后只移除目录与位置关系，文章和附件继续保留。失去全部位置的文章可从左侧 **未归类** 中找到，再选择新位置。

删除文章会先移入 **回收站**。恢复后为草稿，检查后可以重新发布。永久删除仅管理员可执行，会同时删除这篇文章的评论和历史版本。

移动目录、移动文章和删除操作均有确认步骤。取消编辑器中的未保存修改时，也会先提示。

## 上传代码与资料

在文章编辑器中展开 **附件 · 代码、案例与资料**，点击 **添加附件**，再选择 **上传文件**。

支持 ZIP、PDF、文本、Markdown、C/C++、Python、Shell、OpenFOAM 配置及常用文档，单个文件最大 50 MB。多个源码文件可以打包成 ZIP。填写下载名称和简短的使用说明，保存文章后，正文下方会出现下载入口。

已有文件可以直接粘贴站内路径或 HTTPS 地址。多篇文章可以共用一个附件。

**下载资源**页面用于查找上传文件、查看引用文章和建立下载条目。删除下载入口只改变文章；删除存储文件会影响所有使用该地址的内容，因此正在被引用的文件需要先从对应文章中移除。

上传的附件通过公开地址提供下载。草稿附件也应是准备公开分享的文件。

## 课程顺序与列表分页

连续课程使用相同的 **系列 / 专栏** 名称，再以 **排序** 控制章节顺序。例如使用 10、20、30，可以方便地插入后续章节。阅读页的首章、上一章、下一章和末章会按同一系列中已发布的课程自动生成。

管理列表每页显示 25 条，公开课程、命令和资料列表每页显示 12 条。底部提供 **第一页、上一页、页码、下一页、最后一页**。切换目录或搜索时回到第 1 页，翻页时保留筛选条件。

## 正文、公式与代码

正文支持 Markdown。行内公式使用 `\( \mathrm{Re}=UL/\nu \)`，独立公式使用 `\[ \nabla\cdot\mathbf{U}=0 \]`。

代码使用带语言标记的代码块，例如：

````markdown
```foam
application icoFoam;
startTime   0;
endTime     0.5;
```
````

常用标记包括 `bash`、`foam`、`cpp`、`python` 和 `json`。代码之后解释输入、参数和预期结果。使用 **预览** 检查排版，再保存或发布。

需要恢复旧正文时，在 **地址与高级设置 → 查看历史版本** 中载入旧版，再保存为新版本。如果另一个窗口已修改同一篇文章，系统会提示版本冲突，当前编辑内容会保留。

## 评论、讨论与用户权限

**评论与讨论**分为文章评论、讨论回复和讨论主题，可以搜索来源、作者或正文，执行隐藏、恢复、关闭和删除。文章编辑器中的 **允许评论** 控制该篇文章的评论区。

| 角色 | 主要权限 |
| --- | --- |
| 管理员 | 目录、内容、附件、社区、成员权限、站点设置和永久删除 |
| 内容编辑 | 目录、内容、附件与编辑历史 |
| 社区版主 | 讨论、回答和评论管理 |
| 普通会员 | 发布和编辑自己的文章、提问、回答、评论与学习记录 |

会员从[作者工作台](/studio/)发布文章，管理员可以调整文章位置或删除内容。**更多管理 → 成员权限**用于修改成员角色，**站点设置**用于修改网站名称与讨论开关。

## 本地文件与 Hexo 发布

本地工程位于 `E:\Hexo`。

| 目录 | 用途 |
| --- | --- |
| `source-openfoam` | 当前网站页面、图片与下载包 |
| `themes/foam-lab` | 当前主题的模板、样式与交互 |
| `tools/content` | 课程、文章和参考资料的本地内容源 |
| `supabase` | 数据库迁移、权限与验证脚本 |
| `.source_foamlab` | 当前 GitHub 源码工作副本 |
| `public-openfoam` | Hexo 生成的网页 |
| `archive` | 旧博客、旧主题、历史部署副本与早期备份 |

`archive/2026-10-03/manifest.json` 记录归档文件的原路径和新位置，归档内容不参与构建与发布。

日常通过后台修改目录和文章，保存后即可生效。修改外观或静态资料后，运行 **启动学习网站.cmd** 预览，再运行 **发布学习网站.cmd** 发布。源码提交到 `foamlab-source` 分支，由 GitHub Actions 构建并部署。

## 备份

**更多管理 → 维护与备份**可以导出内容、目录结构和站点设置。导出文件含附件地址，附件本体需要另行保存。后台正文与本地内容源分别存放，批量更新前先备份并比较版本。

网站布局规范见[设计规范](/admin/design/)。发布情况可以在[GitHub Actions](https://github.com/foamlabshark/foamlabshark.github.io/actions)查看。
