<h2>1 标量输运与控制体积分</h2>
<p>本讲研究恒速场中的无量纲标量 T，T 不表示温度。\(U=(1 0 0) m/s\)，扩散系数为零，1 m 长域采用周期边界。连续方程仅含时间与对流项，精确解保持初始幅值和形状平移，可用于检验离散误差。</p>
<p>标量方程为 \(\frac{\partial T}{\partial t}+\nabla\cdot(\boldsymbol U T)=\nabla\cdot(D\nabla T)+S\)。对控制体积分后，时间项表示单元标量总量的变化，源项按体积积分，对流与扩散项依据散度定理转为面通量求和。这一积分形式构成有限体积离散的基础。</p>
<p>固定网格的时间项可近似为单元体积乘平均值变化率。面体积通量 \(phi=U_{f}\cdot S_{f}\)，Sf 为有向面积。T 无量纲时，phi·Tf 的单位为 \(m^{3}/s\)；T 为摩尔浓度时，其单位为 mol/s。量纲取决于变量定义，字段名称 T 不限定其表示温度。</p>
<p>内部面使用唯一通量，相邻单元以相反符号计入。全部单元方程求和后，内部通量抵消，仅保留外边界和体积源贡献。因此，共享通量可保证总体收支，但不保证局部分布精度，后者仍取决于面值近似。</p>
<h2>2 从单元中心计算面值</h2>
<p>x 方向 100 个单元，间距 0.01 m，其余边界为 empty，速度与标量遵循相同约束。未知量位于单元中心，通量通过面计算，因此需从邻近单元构造面值，对流格式的主要差异在此产生。</p>
<p>速度沿正 x 方向时，一阶上风以左侧上游单元值作为面值。该近似忽略上游中心至面位置的梯度变化，通常具有较好的稳定性，但其数值耗散会使脉冲展宽、峰值降低。</p>
<p>线性插值按两侧单元值及几何距离计算面值。均匀一维网格上，面值为相邻中心值的算术平均，位于二者之间。该近似在光滑区域通常精度较高，但中心型对流离散的最终单元解仍可能在陡峭分布附近过冲或欠冲，需另行检查场极值。</p>
<p>linearUpwind 从上游值出发，使用梯度与从上游中心指向面的位移点积构造修正。它因而同时依赖对流格式和梯度格式。本例 gradSchemes 使用 Gauss linear，这项设置会影响梯度修正的数值。只记录 linearUpwind 名称而不记录梯度计算方式，不能完整复现离散方程。</p>
<p>limitedLinear 和 vanLeer 对高阶修正施加限制。其限制强度随局部梯度关系变化，在光滑区域保留较多高阶信息，在急剧变化附近抑制振荡。限制器兼顾分辨率与有界性的方式不同，需要用场极值、形状误差及总量共同比较。增加限制可以减少某些非物理振荡，也可能增加局部耗散。</p>
<h2>3 时间离散与数值扩散</h2>
<p>五种空间格式统一采用隐式 Euler。时间项由新旧时刻差商近似，空间项取新时刻值，每步求解线性系统。该时间离散为一阶，提高空间插值阶数并不改变时间精度。</p>
<p>对于一维正向常速度和一阶上风，离散方程可写为 \((T_{i}^{n+1}-T_{i}^{n})/\Delta t+U(T_{i}^{n+1}-T_{i}-1^{n+1})/\Delta x=0\)。使用泰勒展开比较连续方程，可见其主导误差含有类似扩散的二阶空间导数。隐式上风的等效数值扩散系数在这一简化模型下约为 \(U\Delta x(1+\mathrm{Co})/2\)。空间上风和隐式时间离散均贡献耗散。</p>
<p>本组 \(\mathrm{Co}=\frac{U\Delta t}{\Delta x}\)=0.5，\(\Delta t=0.005\,\mathrm{s}\)，终止时间为 0.5 s，共推进一百步。按上述估算，上风等效数值扩散系数约为 \(0.0075\,\mathrm{m}^{2}/s\)。真实物理扩散系数为零，因而脉冲的展宽来自离散过程。这一估算适用于所列线性均匀网格模型，用于解释趋势；定量误差仍以实际精确解比较为准。</p>
<p>隐式时间离散还会影响不同空间格式的排序。例如某个高阶格式在很小时间步下能较好保留峰值，但时间步较大时，一阶时间耗散可能成为主要误差。若只看到最终曲线较宽，不能把全部变化归因于空间上风。第十六讲保持网格不变改变 Co，进一步分离时间步的影响。</p>
<p>将上述一阶上风方程整理后，可得 \((1+\mathrm{Co})T_{i}^{n+1}-CoTi-1^{n+1}=T_{i}^{n}\)。新时刻各单元值相互关联，需要整体求解；周期连接还使最左侧单元与最右侧单元耦合。对这一简单线性问题，对角项与邻接项具有有利于保持非负的系数结构。高阶梯度修正改变面值组合后，局部系数及修正项的符号结构也会改变，因而仅增加空间阶数不能保证原有极值约束。</p>
<p>离散方程求解过程中，线性残差用于衡量当前迭代解是否满足这组代数方程。把线性容差从较松改为较严，会减小代数求解误差，但对流通量中已经选定的上风近似仍然存在。因此当残差已充分下降后，再增加迭代次数不能恢复被数值扩散削弱的高斯峰；应通过格式、网格或时间步对照改变离散误差。这一区分决定了结果不准确时应修改哪个文件。</p>
<p>从单元守恒看，若某一面值偏高，上游单元流出过多，下游单元流入也同样过多；下一时间步两侧分布已改变，误差继续由相邻面传播。经过较多时间步后，局部面值误差可积累为明显的整体形状变化。运行时长因而也是误差比较条件之一，不能将较短运行的峰值与较长运行的峰值直接用于评价格式。周期问题尤其便于固定平移距离后比较累计误差。</p>
<h2>4 精确平移解与初始场</h2>
<p>初值 \(T_{0}(x)=\exp (-((x-0.25)/0.06)^{2})\)，峰中心为 0.25 m。0/T 已保存 100 个单元值。中心采样位置未恰好落在峰顶，离散最大值约为 0.99308，峰值比较应使用实际采样初值。</p>
<p>无限域精确解为 \(T(x,t)=T_{0}(x-Ut)\)。周期域需要先把 x−Ut 映射到长度为一米的基本区间。本例终止时刻为零点五秒，峰中心由零点二五米移至零点七五米。速度不变且没有扩散时，精确解的幅值、宽度和总体积分均保持不变。</p>
<p>数值误差计算使用相同单元中心及实际保存时刻。若一组使用节点值，另一组使用单元中心值，会引入额外采样差异。比较单元平均值与点值时也需要明确近似；本课程当前检查按相同中心位置生成参考数组，与已保存的单元数值逐项比较。</p>
<p>一个具体守恒例题是：公共面体积通量为 \(0.01\,\mathrm{m}^{3}/s\)，面无量纲标量值为二，则标量通量为 \(0.02\,\mathrm{m}^{3}/s\)。该通量在上游单元方程中表示流出，在下游单元中表示流入。两个单元相加时贡献为零，但若面值二偏离真实面值，两个单元的局部变化率仍同时存在误差。总量抵消不能代替局部精度验证。</p>
<h2>5 文件设置及独立运行</h2>
<p>upwind、linear、linearUpwind、limitedLinear、vanLeer 五组目录均标记 Co0.5。网格、初值、速度、步长及终止时刻一致，仅对流格式在 fvSchemes 中不同。以下给出 upwind 配置。</p>
<pre><code>ddtSchemes { default Euler; }
gradSchemes { default Gauss linear; }
divSchemes
{
    default none;
    div(phi,T) Gauss upwind;
}
laplacianSchemes { default Gauss linear corrected; }</code></pre>
<p>Gauss 表示把散度积分写为面通量求和，upwind 指定对流面值的计算方法。扩散项虽然保留离散格式，但 transportProperties 中 DT 为零，该项不产生物理扩散。default none 要求求解器使用的离散项显式给出，缺少 div(phi,T) 时会在构造方程过程中报错。</p>
<pre><code>source /usr/lib/openfoam/openfoam2512/etc/bashrc
cd 代码/upwind_Co0.5
./Allrun.sh</code></pre>
<p>脚本依次运行 blockMesh、checkMesh、scalarTransportFoam 和速度大小后处理。scalarTransportFoam 读取给定 U 并求解 T，不求解动量方程或压力速度耦合。</p>
<p>fvSolution 中 T 使用 PBiCGStab 和 DILU，绝对容差为 \(10^{-12}\)，relTol 为零，用于减小线性求解误差对格式对照的影响。</p>
<p>周期边界在网格和场文件中均需配套。left 与 right 在 blockMeshDict 中互为 neighbourPatch，0/T 和 0/U 中均采用 cyclic。若仅在某一个场中改为固定值，就改变了原问题的边界输运，不再是相同周期平移实验。重新生成不同数量的网格时，非均匀初始列表也必须与新单元数一致。</p>

<h2>7 误差范数及格式选择</h2>
<p>令单元误差为 \(e_{i}=T_{i}-T_{i},exact\)，体积加权 L1 为 \(\sum |e_{i}|V_{i}/\sum Vi\)。对于本例等体积单元，它等于各绝对误差的算术平均。L2 为加权平方误差平均的平方根，对较大局部误差更敏感；最大误差给出全域最严重的偏离。不同范数强调的误差特征不同，比较前应统一公式和归一化。</p>
<p>例如四个等体积单元误差分别为零点一、负零点一、零点二、负零点二，带符号平均为零，但 L1 为零点一五。该结果表明正负误差可以在积分中抵消。对于非负浓度，局部负值还会违反变量约束，即使总体守恒也不能忽略。</p>
<p>格式选择应依据所需输出量。若关注非负分布或界面附近的极值，可优先检查限制器及极值范围；若关注光滑波形的位置和幅值，则需同时比较相位和幅值误差。离散精度、稳定性与有界性分别描述近似误差、误差随推进的控制能力和数值范围限制，不能用“高阶”一个名称概括。</p>
<p>扩展实验应保留当前基准，独立减小时间步或加密网格，比较同一时刻的误差。改变网格并保持 Co 时，时间步也随之改变，所得误差下降同时包含空间和时间改善。需要估计空间收敛阶时，应先把时间误差控制到较小水平；需要估计时间收敛阶时，则保持空间网格不变。完整记录初值、边界和误差定义，才能判断结果变化来自哪一项设置。</p>

<h2>9 离散守恒与修正方程</h2>
<p>标量有限体积方程可写为 \(\frac{V_P(T_P^{n+1}-T_P^n)}{\Delta t}+\sum_f F_f=S_P V_P\)。对所有单元相加，内部面的 F_f 因符号相反抵消。周期、无源情况下，标量积分因而保持不变。这个推导没有要求每个单元值等于精确解，因此总量守恒并不排除峰值衰减、相位偏移和过冲。误差评估须同时报告场分布与积分收支。</p>
<p>对于一维恒速 \(U&gt;0\) 的后向 Euler 和上风组合，在新时刻展开时间差分与空间差分，得到 \(T_{t}+UT_{x}\approx (\Delta t/2)T_{tt}+(U\Delta x/2)T_{xx}\)。再用原方程的主导关系 \(T_{tt}\approx U^{2}T_{xx}\)，可得 \(D_{\mathrm{num}}\approx U\Delta x(1+\mathrm{Co})/2\)。该项说明即使真实扩散系数为零，离散过程仍可使光滑脉冲展宽。它也说明本课程减小 Co 时，后向 Euler 的时间耗散贡献会减弱。</p>
<p>上述修正方程只保留主导截断项，适用于光滑分布、均匀网格和给定格式组合。限制器在陡峭区改变重构行为后，误差不再由一个全域常数扩散系数完整描述。因此本讲先用解析推导解释趋势，再用相同时间与位置的计算结果检验峰值、极值及误差范数。</p>
